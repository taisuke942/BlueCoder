実行用BATはShift_JIS（CP932）・CRLFです。 編集後もこの形式で保存してください。日本語名をUnicodeエスケープへ変換する必要はありません。閲覧用の.txtはUTF-8なので、拡張子だけを.batへ変えて使わないでください。

今後は名前を直接書き換えるだけ

Ａ２用

set "NEW_VALUE=Ａ２テストＤＢ"

Ｂ７用

set "NEW_VALUE=Ｂ７テストＤＢ"

同じINI・同じセクションを対象にする場合、BATをコピーしてNEW_VALUEの１行を変更します。VBSは変更しません。

set "INI_FILE=%~dp0test.ini"
set "TARGET_SECTION=ODBC\u63A5\u7D9A\u6587\u5B57\u5217"
set "TARGET_KEY=Database"
set "NEW_VALUE=Ａ２テストＤＢ"
set "INI_CHARSET=shift_jis"
set "EXPECTED_MATCHES=2"

対象は[ODBC接続文字列]の有効な接続行の末尾Databaseです。２行とも同じNEW_VALUEにします。コメント行と別セクションは対象外です。EXPECTED_MATCHES=2により、対象が２件そろわないと書き込み前に停止します。意図的に件数を変えるときだけ、この数も変更します（0は件数制限なし）。

設定値の受け渡しを変更しました

v5のBATは値を５つの位置引数に並べず、INI_FILE・NEW_VALUE・TARGET_KEYなどの環境変数をVBSが名前で読み取ります。全角の名前は変換せず、そのまま受け取ります。必須設定が空のときに止める検査は残しています。

起動時の表示は INI updater v5 (environment / ODBC Database tail)。２行とも変更すると Matched: 2 value(s). と Updated: 2 value(s). が表示されます。

書き込まずに対象件数だけ確認

set_A2.bat /check

CHECK ONLY: no files written. と表示し、ファイルは変更しません。通常のダブルクリック実行は書き換えを行います。/checkは対象解析の確認で、書込権限などの通し確認ではありません。

対応範囲・安全上の注意

接続情報は１設定につき１行で、Databaseが最後の項目である形式を対象とします。接続文字列全体を引用符で囲む形式、Databaseの後に別項目がある形式、行末コメントは今回の対象外です。新しい値には空白・制御文字・引用符・波括弧・セミコロン・#を使用できません。%を含む値はBATの展開規則が関わるため、この雛形では使用しないでください。

バックアップは自動生成しません。更新データを検証する一時ファイルは処理完了時に削除します。書き込み途中の障害に対して元ファイルを復元する仕組みではありません。実際の職場のINI・認証情報はこの公開リポジトリに含めていません。SQL Serverへ接続する処理もありません。
