AccessフォームからVB6フォームを作成するVBS

結論：
このVBSを実行すると、Accessファイルから直接、 VB6で読み込める.frmファイルを作成できます。
CSVやAccessフォーム定義テキストを、自分で用意する必要はありません。

処理の流れ

Accessファイル（.accdb／.mdb）
↓
AccessFormToVB6.vbsを実行
↓
VB6用の.frmファイルが作成される

使用するファイル

AccessFormToVB6.vbs 使い方の説明

GitHub PagesでこのHTMLを公開する場合は、 このHTML、VBS、使い方テキストの3ファイルを 同じフォルダへ置いてください。

使い方

  1. AccessFormToVB6.vbsをダウンロードします。
  2. 変換するAccessファイルを閉じます。
  3. AccessFormToVB6.vbsをダブルクリックします。
  4. 変換したい.accdbまたは.mdbを選びます。
  5. Accessファイルと同じ場所に、VB6_Formsフォルダが作られます。
  6. その中に、Accessフォームごとの.frmファイルが作られます。

作成されるファイル

Accessファイルがあるフォルダ
├─ Sample.accdb
└─ VB6_Forms
   ├─ frm顧客入力.frm
   ├─ frm商品登録.frm
   └─ 変換結果.txt

変換結果.txtには、成功したフォーム数や、 変換できなかったコントロールの情報が記録されます。

VB6へ追加する方法

VB6で対象プロジェクトを開き、次の順に操作します。

プロジェクト
  ↓
フォームの追加
  ↓
既存

その後、VB6_Formsフォルダ内に作成された .frmファイルを選びます。

CSVとテキストファイルは必要か

ファイル 今回のVBSで必要か 説明
CSV 不要 コントロール一覧を確認するための補助データでした。
Accessフォーム定義テキスト 不要 VBSがAccessファイルを直接読み取るため、自分で出力する必要はありません。
VB6の.frm 必要 このVBSが自動作成し、VB6へ追加する実際のフォームファイルです。

自動で移せる主な内容

  • フォームのおおよその大きさ
  • ラベル
  • テキストボックス
  • コマンドボタン
  • チェックボックス
  • オプションボタン
  • コンボボックス
  • リストボックス
  • 各コントロールの位置と大きさ

自動では移らない内容

このツールが作成する.frmは、 VB6画面のひな形です。 Accessのすべての機能を完全変換するものではありません。
  • Access VBA
  • Accessマクロ
  • RecordSourceによるデータ表示
  • ControlSourceによるテーブルとの自動連携
  • サブフォーム
  • 条件付き書式
  • Access固有の特殊コントロール
  • ボタンを押したときの処理

これらは、作成されたVB6フォームに対して、 ADOやDAO、VB6のイベントコードを追加して仕上げます。

最終的な整理

必要な操作は簡単です。

1. VBSをダブルクリックする
2. Accessファイルを選ぶ
3. 作成された.frmをVB6へ追加する

CSVやテキストファイルを途中で扱う必要はありません。
