WINDOWS EXCEL / VBA / 2026-10-24 · v1.0

印影をPNGにして、
勤怠Excelに埋め込む。

職場のファイルを共有せずに導入できる、新規作成の印鑑マクロです。氏名・日付などを入力すると、赤い丸印を生成して、選択したセルに配置します。

VBAモジュールをダウンロード コピー用の全コード
WHAT THIS MAKES

2種類の印鑑を用意しました

氏名だけの丸印

Stamp_Name

上段・日付・氏名の丸印

Stamp_Date

上の図は構成を示す説明図です。実際の文字の形や余白は、作成側PCのフォントと入力文字数によって変わります。「山田」は入力例です。

作成環境Windows版Excel。32ビット・64ビット用のAPI宣言を同梱し、旧VBA用の分岐も含めています。Mac・ブラウザー版・iPhone版でのマクロ実行は対象外です。
Excelの保存形式.xlsのまま使用できます。マクロを保管する場合は.xlsmでも構いません。
氏名・上段それぞれ1～6文字。正しいサロゲートペアは1文字として扱います。実際に表示できる字形は、作成側にあるフォントに依存します。
画像サイズ1200×1200ピクセルの透過PNG。配置時の一辺は初期値18mm、6～40mmで指定できます。外周円の周りには少し余白があります。
押印先選択したセルの中央。結合セルでは結合範囲の中央。セルが小さくても、入力した大きさを維持します。
提出時画像をExcelに埋め込みます。受取側で作成マクロを実行したり、画像ファイルを別途用意したりする必要はありません。
INSTALL ONCE

最初の導入

まず、空のテスト用Excelファイルで実行してください。既存の印鑑ツールのコードを置き換える必要はありません。

  1. このページ上部からStampRaster.basを保存します。
  2. Excelでテスト用ブックを開き、Alt + F11を押します。
  3. 左側で対象ブックのVBAProjectを選びます。左側が見えない場合はCtrl + Rです。
  4. VBA画面の［ファイル］→［ファイルのインポート］で、StampRaster.basを選びます。標準モジュールStampRasterが追加されます。
  5. ［デバッグ］→［VBAProjectのコンパイル］で構文を確認します。コードを変更していないためメニューが無効な場合は、そのまま次へ進みます。
  6. Alt + QでExcelに戻ります。

日本語WindowsのVBEで取り込めるよう、.basはCP932（Shift-JIS系）で保存しています。追加の参照設定や外部ソフトのインストールは不要です。

.basの取り込みが使えない場合

コピー用の全コードを開き、先頭のOption Explicitから最後までコピーしてください。VBA画面の［挿入］→［標準モジュール］で新しいモジュールを追加し、その中に全体を貼り付けます。シートのコード欄やThisWorkbookには貼り付けません。

USE

印鑑を押す

  1. 印鑑を置きたいセルを1つ選択します。結合セルでも使えます。
  2. Alt + F8を押します。
  3. 氏名だけならStamp_Name、日付入りならStamp_Dateを選び、［実行］します。
  4. 氏名、必要なら上段の文字と日付、最後に画像の大きさを入力します。
  5. 位置と見た目を確認して保存します。新規ブックの最初の保存は［名前を付けて保存］→［Excel 97-2003 ブック（*.xls）］を選びます。既存の.xlsは通常どおりCtrl + Sで保存します。マクロを残すため、.xlsxには変更しません。

一度入力した氏名・上段・サイズは、そのマクロを入れたブックを開いている間の次回入力に引き継ぎます。日付の初期値は実行日の当日です。キャンセルした場合は押印しません。

旧ツールで作った印鑑は、自動では削除しません。同じ場所に重なっている場合は、旧印鑑だけを選んで手動で削除してください。画像の名前はStampPNG_1のようになります。

提出するのはExcelファイルだけです。
生成途中のPNGは、埋め込み後に一時フォルダーから削除します。ネットワーク通信や外部サービスへの送信は行いません。
WHY THIS DESIGN

変形への対策

印影は、固定ピクセルの画像上に円・文字・線を直接描いて生成します。画面のスクリーンショット、ExcelのCopyPicture、一時グラフへの貼り付けは使いません。作成時の画面拡大率を画像サイズの計算に取り込みません。

そのPNGをLinkToFile:=msoFalse・SaveWithDocument:=msoTrueで埋め込み、配置する大きさをmmからポイントへ換算します。セルとのサイズ非連動と、縦横比固定も設定します。

防げる範囲には限界があります。
印鑑内部の文字・枠・線は1枚の画像に確定します。ただし、Excelが画像全体の寸法・配置を変えてしまう不具合まで、あらゆる環境で保証するものではありません。
VERIFY

最初に確認すること

  1. 空のテスト用ブックに印鑑を押し、.xls形式で保存します。
  2. Excelをいったん終了して開き直し、印鑑が残り、形が保たれているか確認します。マクロの再実行は不要です。
  3. ノート本体と外付けディスプレイの両方で表示し、円の形・文字・印刷プレビューを確認します。

テストで確認できたら、実際の勤怠.xlsにも、同じ［ファイルのインポート］手順で追加してください。

この配布版の確認状況：コード構造、APIの型、32/64ビット分岐、画像埋め込み指定、入力検査、リソースの後始末、配布時の文字コードを点検しています。Windows版Excel上での実行と、実際の.xls保存・再オープンは未検証です。

エラーが出たとき

表示・状況確認すること
図形の編集が保護されている職場で編集を許可されているシートで実行します。コードは保護を解除しません。
「名前が適切ではありません」「名前が重複」などのコンパイルエラー同じコードを2回入れていないか、新しい標準モジュールに全コードを入れたか確認します。
マクロが実行できない職場で許可されているマクロ実行方法を使用します。組織の制限を回避する処理は含めていません。
文字が四角になる作成側PCで使えるフォントに、その字形があるか確認します。一般的な日本語はMS Gothicを使用し、取得できない場合は代替フォントを使用します。
GDI+コード、Windowsエラーが表示されるエラー番号とメッセージを控えてください。職場のファイルを送らず、その情報だけで追加調査できます。

' 氏名だけの丸印。名前は縦に配置します。
Public Sub Stamp_Name()
    SU_RunStamp False
End Sub

' 上段の文字・日付・氏名を入れた丸印。
Public Sub Stamp_Date()
    SU_RunStamp True
End Sub

Private Sub SU_RunStamp(ByVal useDate As Boolean)
    Dim ws As Worksheet
    Dim target As Range
    Dim pic As Shape
    Dim answer As Variant
    Dim nameText As String, labelText As String, dateText As String
    Dim chosenDate As Date
    Dim diameterMm As Double, sizePt As Double
    Dim leftPt As Double, topPt As Double
    Dim pngPath As String
    Dim errNumber As Long, errText As String
    Dim finished As Boolean

    On Error GoTo Failed

#If Mac Then
    MsgBox "この印鑑作成マクロは Windows 版 Excel 専用です。", vbInformation
    Exit Sub
#End If

    If ActiveWorkbook Is Nothing Then
        MsgBox "印鑑を押すブックを開いてください。", vbInformation
        Exit Sub
    End If
    If TypeName(Selection) <> "Range" Then
        MsgBox "印鑑を押すセルを選択してから実行してください。", vbInformation
        Exit Sub
    End If

    ' 入力ダイアログを出す前に押印先を確定します。
    Set target = Selection.Cells(1, 1)
    Set target = target.MergeArea
    Set ws = target.Worksheet

    If ws.ProtectDrawingObjects Then
        MsgBox "このシートでは図形の編集が保護されています。" & vbCrLf & _
               "編集できるシートで実行してください。", vbExclamation
        Exit Sub
    End If
    If target.Width <= 0 Or target.Height <= 0 Then
        MsgBox "非表示の行・列には押せません。表示されているセルを選んでください。", vbInformation
        Exit Sub
    End If

    If Len(mStampLastName) = 0 Then mStampLastName = STAMP_DEFAULT_NAME
    If Len(mStampLastLabel) = 0 Then mStampLastLabel = STAMP_DEFAULT_LABEL
    If mStampLastMm = 0 Then mStampLastMm = STAMP_DEFAULT_MM

    answer = Application.InputBox( _
        Prompt:="印鑑に入れる氏名を入力してください（1～6文字）。", _
        Title:="PNG 印鑑 - 氏名", Default:=mStampLastName, Type:=2)
    If VarType(answer) = vbBoolean Then Exit Sub
    nameText = Trim$(CStr(answer))
    SU_CheckText nameText, "氏名", 6

    If useDate Then
        answer = Application.InputBox( _
            Prompt:="上段の文字を入力してください（1～6文字）。例: 確認、承認、部署名", _
            Title:="PNG 日付印 - 上段", Default:=mStampLastLabel, Type:=2)
        If VarType(answer) = vbBoolean Then Exit Sub
        labelText = Trim$(CStr(answer))
        SU_CheckText labelText, "上段の文字", 6

        answer = Application.InputBox( _
            Prompt:="日付を西暦で入力してください。例: 2026/10/24", _
            Title:="PNG 日付印 - 日付", Default:=Format$(Date, "yyyy/mm/dd"), Type:=2)
        If VarType(answer) = vbBoolean Then Exit Sub
        chosenDate = SU_ParseDate(Trim$(CStr(answer)))
        dateText = Format$(chosenDate, "yyyy.mm.dd")
    End If

    answer = Application.InputBox( _
        Prompt:="印鑑画像の一辺を mm で入力してください（6～40）。" & vbCrLf & _
                "セルが小さくても指定した大きさを保ちます。", _
        Title:="PNG 印鑑 - 大きさ", Default:=mStampLastMm, Type:=1)
    If VarType(answer) = vbBoolean Then Exit Sub
    diameterMm = CDbl(answer)
    If diameterMm < STAMP_MIN_MM Or diameterMm > STAMP_MAX_MM Then
        Err.Raise vbObjectError + 4101, "StampRaster", "大きさは 6～40 mm の範囲で指定してください。"
    End If

    ' 固定ピクセルの PNG を直接生成。Excel の画面コピーは使いません。
    pngPath = CreateStampPng(nameText, labelText, dateText, useDate)
    SU_CheckPng pngPath

    ' mm → point。画像の埋め込みサイズに画面 DPI を使いません。
    sizePt = diameterMm * 72# / 25.4
    leftPt = target.Left + (target.Width - sizePt) / 2#
    topPt = target.Top + (target.Height - sizePt) / 2#
    If leftPt < 0 Then leftPt = 0
    If topPt < 0 Then topPt = 0

    Set pic = ws.Shapes.AddPicture( _
        Filename:=pngPath, LinkToFile:=msoFalse, SaveWithDocument:=msoTrue, _
        Left:=leftPt, Top:=topPt, Width:=sizePt, Height:=sizePt)

    With pic
        .Placement = xlFreeFloating
        .LockAspectRatio = msoTrue
        .Name = SU_NewShapeName(ws)
        .AlternativeText = "PNG印鑑: " & nameText & IIf(useDate, " " & dateText, "")
    End With

    mStampLastName = nameText
    mStampLastMm = diameterMm
    If useDate Then mStampLastLabel = labelText
    finished = True

    ' 画像はすでにブックに埋め込まれています。一時ファイルを削除。
    DeleteStampTemp pngPath
    pngPath = vbNullString

    MsgBox "印鑑を押しました。位置を確認して、通常どおり保存してください。" & vbCrLf & _
           "既存の印鑑がある場合は、必要に応じて手動で削除してください。", vbInformation
    Exit Sub

Failed:
    errNumber = Err.Number
    errText = Err.Description
    On Error Resume Next
    If Not finished Then
        If Not pic Is Nothing Then pic.Delete
    End If
    If Len(pngPath) > 0 Then DeleteStampTemp pngPath
    On Error GoTo 0
    MsgBox "印鑑を作成できませんでした。" & vbCrLf & _
           "エラー番号: " & CStr(errNumber) & vbCrLf & errText, vbExclamation
End Sub

Private Sub SU_CheckText(ByVal value As String, ByVal fieldName As String, ByVal maxChars As Long)
    Dim i As Long, n As Long, unit1 As Long, unit2 As Long
    Dim nonBlank As String
    nonBlank = Replace$(Replace$(value, " ", ""), ChrW$(&H3000), "")
    If Len(nonBlank) = 0 Then
        Err.Raise vbObjectError + 4102, "StampRaster", fieldName & "を入力してください。"
    End If
    i = 1
    Do While i <= Len(value)
        unit1 = AscW(Mid$(value, i, 1)) And &HFFFF&
        If unit1 < 32 Or (unit1 >= 127 And unit1 <= 159) Then
            Err.Raise vbObjectError + 4103, "StampRaster", fieldName & "に改行や制御文字は使えません。"
        End If
        If unit1 >= &HD800& And unit1 <= &HDBFF& Then
            If i = Len(value) Then GoTo InvalidUnicode
            unit2 = AscW(Mid$(value, i + 1, 1)) And &HFFFF&
            If unit2 < &HDC00& Or unit2 > &HDFFF& Then GoTo InvalidUnicode
            i = i + 1
        ElseIf unit1 >= &HDC00& And unit1 <= &HDFFF& Then
            GoTo InvalidUnicode
        End If
        n = n + 1
        i = i + 1
    Loop
    If n > maxChars Then
        Err.Raise vbObjectError + 4104, "StampRaster", fieldName & "は " & CStr(maxChars) & " 文字以内にしてください。"
    End If
    Exit Sub
InvalidUnicode:
    Err.Raise vbObjectError + 4105, "StampRaster", fieldName & "に扱えない文字列が含まれています。入力し直してください。"
End Sub

Private Function SU_ParseDate(ByVal value As String) As Date
    Dim parts As Variant
    Dim y As Long, m As Long, d As Long
    Dim answer As Date
    value = Replace$(Replace$(value, ".", "/"), "-", "/")
    parts = Split(value, "/")
    If UBound(parts) <> 2 Then GoTo BadDate
    If Not (CStr(parts(0)) Like "####") Then GoTo BadDate
    If Len(parts(1)) < 1 Or Len(parts(1)) > 2 Then GoTo BadDate
    If Len(parts(2)) < 1 Or Len(parts(2)) > 2 Then GoTo BadDate
    If CStr(parts(1)) Like "*[!0-9]*" Then GoTo BadDate
    If CStr(parts(2)) Like "*[!0-9]*" Then GoTo BadDate
    y = CLng(parts(0)): m = CLng(parts(1)): d = CLng(parts(2))
    If y < 1900 Or y > 9999 Or m < 1 Or m > 12 Or d < 1 Or d > 31 Then GoTo BadDate
    answer = DateSerial(y, m, d)
    If Year(answer) <> y Or Month(answer) <> m Or Day(answer) <> d Then GoTo BadDate
    SU_ParseDate = answer
    Exit Function
BadDate:
    Err.Raise vbObjectError + 4106, "StampRaster", "日付は 2026/10/24 のように、実在する西暦の日付を入力してください。"
End Function

Private Function SU_NewShapeName(ByVal ws As Worksheet) As String
    Dim candidate As String, index As Long
    Dim found As Shape
    index = 1
    Do
        candidate = "StampPNG_" & CStr(index)
        Set found = Nothing
        On Error Resume Next
        Set found = ws.Shapes(candidate)
        On Error GoTo 0
        If found Is Nothing Then Exit Do
        index = index + 1
    Loop
    SU_NewShapeName = candidate
End Function

Private Sub SU_CheckPng(ByVal filePath As String)
    Dim fileNumber As Integer, isOpen As Boolean
    Dim b(0 To 23) As Byte
    Dim w As Double, h As Double
    Dim eNumber As Long, eText As String
    On Error GoTo Failed
    fileNumber = FreeFile
    Open filePath For Binary Access Read As #fileNumber
    isOpen = True
    If LOF(fileNumber) < 33 Then GoTo BadPng
    Get #fileNumber, 1, b
    Close #fileNumber
    isOpen = False
    If b(0) <> 137 Or b(1) <> 80 Or b(2) <> 78 Or b(3) <> 71 Or _
       b(4) <> 13 Or b(5) <> 10 Or b(6) <> 26 Or b(7) <> 10 Then GoTo BadPng
    If b(8) <> 0 Or b(9) <> 0 Or b(10) <> 0 Or b(11) <> 13 Then GoTo BadPng
    If b(12) <> 73 Or b(13) <> 72 Or b(14) <> 68 Or b(15) <> 82 Then GoTo BadPng
    w = CDbl(b(16)) * 16777216# + CDbl(b(17)) * 65536# + CDbl(b(18)) * 256# + b(19)
    h = CDbl(b(20)) * 16777216# + CDbl(b(21)) * 65536# + CDbl(b(22)) * 256# + b(23)
    If w <> 1200 Or h <> 1200 Then GoTo BadPng
    Exit Sub
BadPng:
    Err.Raise vbObjectError + 4107, "StampRaster", "生成した PNG 画像の確認に失敗しました。印鑑は貼り付けていません。"
Failed:
    eNumber = Err.Number: eText = Err.Description
    On Error Resume Next
    If isOpen Then Close #fileNumber
    On Error GoTo 0
    Err.Raise eNumber, "StampRaster", eText
End Sub

' === RENDER PROCEDURES ===
' [PUBLIC] 入力から透過PNGを生成。返された一時ファイルは埋め込み後に削除。
Public Function CreateStampPng(ByVal stampName As String, _
    ByVal topLabel As String, ByVal dateText As String, _
    ByVal dateStyle As Boolean) As String

    Dim ctx As SR_Context
    Dim startupData(0 To 5) As Long
    Dim glyphs() As String, labelGlyphs() As String
    Dim charCount As Long, labelCount As Long, i As Long
    Dim encoder As SR_Guid
    Dim fontName As String, encoderText As String, filePath As String
    Dim box As SR_RectF
    Dim slotHeight As Single, chord As Single
    Dim eNumber As Long, eDescription As String
    On Error GoTo Failed

    stampName = Trim$(stampName)
    topLabel = Trim$(topLabel)
    charCount = SR_SplitCharacters(stampName, glyphs)
    If charCount < 1 Or charCount > 6 Then
        Err.Raise vbObjectError + 731, "CreateStampPng", "氏名は1～6文字で入力してください。"
    End If
    If dateStyle Then
        labelCount = SR_SplitCharacters(topLabel, labelGlyphs)
        If labelCount < 1 Or labelCount > 6 Then
            Err.Raise vbObjectError + 732, "CreateStampPng", "上段の文字は1～6文字で入力してください。"
        End If
        If Not dateText Like "####.##.##" Then
            Err.Raise vbObjectError + 733, "CreateStampPng", "日付の書式は yyyy.mm.dd です。"
        End If
    End If

    ' ULONG_PTRを含むStartupInputはx86=16byte、x64=24byte。
    ' 24byteをゼロ初期化し、先頭DWORDのVersionだけ1にする。
    startupData(0) = 1
    SR_Check SR_GdiplusStartup(ctx.Token, startupData(0), 0), "GDI+初期化"
    SR_Check SR_GdipCreateBitmapFromScan0(SR_PIXELS, SR_PIXELS, 0, _
        SR_PIXEL_ARGB, 0, ctx.Bitmap), "画像の作成"
    SR_Check SR_GdipBitmapSetResolution(ctx.Bitmap, 96!, 96!), "画像解像度"
    SR_Check SR_GdipGetImageGraphicsContext(ctx.Bitmap, ctx.Graphics), "描画の準備"
    SR_Check SR_GdipSetPageUnit(ctx.Graphics, SR_UNIT_PIXEL), "ピクセル単位"
    SR_Check SR_GdipSetSmoothingMode(ctx.Graphics, 4), "輪郭の描画品質"
    SR_Check SR_GdipSetTextRenderingHint(ctx.Graphics, 4), "文字の描画品質"
    SR_Check SR_GdipGraphicsClear(ctx.Graphics, 0), "背景の透明化"
    SR_Check SR_GdipCreatePen1(SR_RED, 24!, SR_UNIT_PIXEL, ctx.Pen), "印枠の準備"
    SR_Check SR_GdipCreateSolidFill(SR_RED, ctx.Brush), "文字色の準備"
    SR_Check SR_GdipDrawEllipse(ctx.Graphics, ctx.Pen, 42!, 42!, 1116!, 1116!), "印枠の描画"

    fontName = SR_FONT_NAME
    If SR_GdipCreateFontFamilyFromName(StrPtr(fontName), 0, ctx.Family) <> 0 Then
        SR_Check SR_GdipGetGenericFontFamilySansSerif(ctx.Family), "代替フォントの準備"
    End If
    ' NoWrap。文字は収まるまで縮小し、三点リーダーで省略しない。
    SR_Check SR_GdipCreateStringFormat(&H1000, 0, ctx.StringFormat), "文字配置の準備"
    SR_Check SR_GdipSetStringFormatAlign(ctx.StringFormat, 1), "横中央揃え"
    SR_Check SR_GdipSetStringFormatLineAlign(ctx.StringFormat, 1), "縦中央揃え"
    SR_Check SR_GdipSetStringFormatTrimming(ctx.StringFormat, 0), "文字省略の無効化"

    If dateStyle Then
        chord = CSng(Sqr(558# * 558# - 170# * 170#))
        SR_Check SR_GdipDrawLine(ctx.Graphics, ctx.Pen, 600! - chord, 430!, _
            600! + chord, 430!), "上の区切り線"
        SR_Check SR_GdipDrawLine(ctx.Graphics, ctx.Pen, 600! - chord, 770!, _
            600! + chord, 770!), "下の区切り線"
        SR_SetRect box, 260!, 170!, 680!, 230!
        SR_DrawFittedText ctx, topLabel, box, 260!
        SR_SetRect box, 110!, 460!, 980!, 280!
        SR_DrawFittedText ctx, dateText, box, 210!
        SR_SetRect box, 260!, 800!, 680!, 230!
        SR_DrawFittedText ctx, stampName, box, 300!
    Else
        If charCount = 1 Then
            SR_SetRect box, 250!, 250!, 700!, 700!
            SR_DrawFittedText ctx, glyphs(1), box, 700!
        Else
            slotHeight = 860! / charCount
            For i = 1 To charCount
                SR_SetRect box, 260!, 170! + (i - 1) * slotHeight, 680!, slotHeight
                SR_DrawFittedText ctx, glyphs(i), box, slotHeight
            Next i
        End If
    End If

    ' Graphicsを解放して描画を確定させてから、PNGエンコーダーで保存。
    SR_Check SR_GdipDeleteGraphics(ctx.Graphics), "描画の確定"
    ctx.Graphics = 0
    encoderText = "{557CF406-1A04-11D3-9A73-0000F81EF32E}"
    If SR_CLSIDFromString(StrPtr(encoderText), encoder) <> 0 Then
        Err.Raise vbObjectError + 734, "CreateStampPng", "PNGエンコーダーの指定に失敗しました。"
    End If
    filePath = SR_NewTempPng()
    SR_Check SR_GdipSaveImageToFile(ctx.Bitmap, StrPtr(filePath), encoder, 0), "PNG保存"
    SR_Release ctx
    CreateStampPng = filePath
    Exit Function

Failed:
    eNumber = Err.Number
    eDescription = Err.Description
    SR_Release ctx
    DeleteStampTemp filePath
    Err.Raise eNumber, "CreateStampPng", eDescription
End Function

Private Sub SR_SetRect(ByRef box As SR_RectF, ByVal x As Single, _
    ByVal y As Single, ByVal w As Single, ByVal h As Single)
    box.X = x: box.Y = y: box.Width = w: box.Height = h
End Sub

Private Sub SR_DrawFittedText(ByRef ctx As SR_Context, ByVal text As String, _
    ByRef box As SR_RectF, ByVal startSize As Single)
    Dim measureBox As SR_RectF, bounds As SR_RectF
    Dim fontSize As Single, fitted As Long, lines As Long, attempt As Long
    SR_SetRect measureBox, 0!, 0!, 20000!, 20000!
    fontSize = startSize
    For attempt = 1 To 50
        SR_Check SR_GdipCreateFont(ctx.Family, fontSize, 0, SR_UNIT_PIXEL, ctx.Font), "フォント作成"
        SR_Check SR_GdipMeasureString(ctx.Graphics, StrPtr(text), Len(text), ctx.Font, _
            measureBox, ctx.StringFormat, bounds, fitted, lines), "文字サイズの測定"
        If bounds.Width <= box.Width * 0.92 And bounds.Height <= box.Height * 0.92 Then
            SR_Check SR_GdipDrawString(ctx.Graphics, StrPtr(text), Len(text), ctx.Font, _
                box, ctx.StringFormat, ctx.Brush), "文字の描画"
            SR_Check SR_GdipDeleteFont(ctx.Font), "フォント解放"
            ctx.Font = 0
            Exit Sub
        End If
        SR_Check SR_GdipDeleteFont(ctx.Font), "フォント解放"
        ctx.Font = 0
        fontSize = fontSize * 0.9
    Next attempt
    Err.Raise vbObjectError + 735, "CreateStampPng", "文字を印鑑内に収められませんでした。"
End Sub

' UTF-16の正しいサロゲートペアは1文字として扱う。
Private Function SR_SplitCharacters(ByVal text As String, ByRef glyphs() As String) As Long
    Dim i As Long, n As Long, u As Long, following As Long, count As Long
    If Len(text) = 0 Then Exit Function
    ReDim glyphs(1 To Len(text))
    i = 1
    Do While i <= Len(text)
        u = AscW(Mid$(text, i, 1)) And &HFFFF&
        n = 1
        If u < 32 Or (u >= 127 And u <= 159) Then
            Err.Raise vbObjectError + 736, "CreateStampPng", "氏名・上段に改行や制御文字は使用できません。"
        ElseIf u >= &HD800& And u <= &HDBFF& Then
            If i = Len(text) Then GoTo BadSurrogate
            following = AscW(Mid$(text, i + 1, 1)) And &HFFFF&
            If following < &HDC00& Or following > &HDFFF& Then GoTo BadSurrogate
            n = 2
        ElseIf u >= &HDC00& And u <= &HDFFF& Then
            GoTo BadSurrogate
        End If
        count = count + 1
        glyphs(count) = Mid$(text, i, n)
        i = i + n
    Loop
    ReDim Preserve glyphs(1 To count)
    SR_SplitCharacters = count
    Exit Function
BadSurrogate:
    Err.Raise vbObjectError + 737, "CreateStampPng", "文字コードが不正です。氏名を入力し直してください。"
End Function

Private Function SR_NewTempPng() As String
    Dim folder As String, buffer As String, prefix As String
    Dim oldPath As String, newPath As String, n As Long, attempt As Long, lastError As Long
    Dim eNumber As Long, eDescription As String
    On Error GoTo Failed
    folder = String$(260, vbNullChar)
    n = SR_GetTempPathW(Len(folder), StrPtr(folder))
    If n = 0 Or n >= Len(folder) Then
        Err.Raise vbObjectError + 738, "CreateStampPng", "Windowsの一時フォルダーを取得できません。"
    End If
    folder = Left$(folder, n)
    If Len(folder) > 245 Then
        Err.Raise vbObjectError + 739, "CreateStampPng", "一時フォルダーのパスが長すぎます。"
    End If
    prefix = "stp"
    For attempt = 1 To 20
        buffer = String$(260, vbNullChar)
        If SR_GetTempFileNameW(StrPtr(folder), StrPtr(prefix), 0, StrPtr(buffer)) = 0 Then
            lastError = Err.LastDllError
            Err.Raise vbObjectError + 740, "CreateStampPng", _
                "一時ファイルを作成できません。Windowsエラー: " & CStr(lastError)
        End If
        oldPath = Left$(buffer, InStr(1, buffer, vbNullChar) - 1)
        newPath = Left$(oldPath, Len(oldPath) - 4) & ".png"
        If SR_MoveFileW(StrPtr(oldPath), StrPtr(newPath)) <> 0 Then
            oldPath = vbNullString
            SR_NewTempPng = newPath
            Exit Function
        End If
        lastError = Err.LastDllError
        DeleteStampTemp oldPath
        oldPath = vbNullString
        ' ERROR_FILE_EXISTS / ERROR_ALREADY_EXISTS のときだけ別名で再試行。
        If lastError <> 80 And lastError <> 183 Then
            Err.Raise vbObjectError + 741, "CreateStampPng", _
                "一時PNGの名前を確保できません。Windowsエラー: " & CStr(lastError)
        End If
    Next attempt
    Err.Raise vbObjectError + 742, "CreateStampPng", "一時PNGの名前を確保できませんでした。"
Failed:
    eNumber = Err.Number: eDescription = Err.Description
    DeleteStampTemp oldPath
    Err.Raise eNumber, "CreateStampPng", eDescription
End Function

' 指定された1ファイルのみを削除。ワイルドカード・フォルダー削除は使用しない。
Public Sub DeleteStampTemp(ByVal filePath As String)
    On Error Resume Next
    If Len(filePath) > 0 Then SR_DeleteFileW StrPtr(filePath)
    On Error GoTo 0
End Sub

Private Sub SR_Check(ByVal status As Long, ByVal operation As String)
    If status <> 0 Then
        Err.Raise vbObjectError + 743, "CreateStampPng", _
            operation & "に失敗しました。GDI+コード: " & CStr(status)
    End If
End Sub

Private Sub SR_Release(ByRef ctx As SR_Context)
    On Error Resume Next
    If ctx.Font <> 0 Then SR_GdipDeleteFont ctx.Font
    If ctx.StringFormat <> 0 Then SR_GdipDeleteStringFormat ctx.StringFormat
    If ctx.Family <> 0 Then SR_GdipDeleteFontFamily ctx.Family
    If ctx.Brush <> 0 Then SR_GdipDeleteBrush ctx.Brush
    If ctx.Pen <> 0 Then SR_GdipDeletePen ctx.Pen
    If ctx.Graphics <> 0 Then SR_GdipDeleteGraphics ctx.Graphics
    If ctx.Bitmap <> 0 Then SR_GdipDisposeImage ctx.Bitmap
    If ctx.Token <> 0 Then SR_GdiplusShutdown ctx.Token
    ctx.Font = 0: ctx.StringFormat = 0: ctx.Family = 0
    ctx.Brush = 0: ctx.Pen = 0: ctx.Graphics = 0
    ctx.Bitmap = 0: ctx.Token = 0
    On Error GoTo 0
End Sub
