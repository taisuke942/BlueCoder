HULFT10 for Windows｜エクスポート・Excel比較・再登録

2026年11月25日作成 ｜ HULFT10 for Windows専用。以前のHULFT8用ファイルは変更していません。

HULFT10の管理情報と履歴をBATで出力し、Excelで一覧・比較します。管理情報はExcelから元のutligen定義カード形式を保持して再出力し、テスト用HULFT10に新規登録できます。

① TXT一括エクスポート
4種類のテキスト ② Excel取込VBA
4シート作成 ③ Excel→TXT出力VBA
元TXT保持方式 ④ HULFT登録BAT
配信・集信管理情報 ⑤ 関連設定のエクスポート
詳細ホスト・転送グループ等

対応範囲と操作の流れ

対象HULFT→TXTTXT→ExcelExcel→TXTHULFT再登録
配信管理情報対応対応対応対応
集信管理情報対応対応対応対応
配信履歴対応対応対象外対象外
集信履歴対応対応対象外対象外

手順： HULFT10で①のBATを実行 → Excelで②のVBAを実行 → 必要な設定を編集 → ③のVBAでTXTを生成 → ④のBATでテスト用HULFT10へ登録。

Excel→TXTで元の定義カードが必要です。 TXTの項目順、コメント、未変更項目をなるべく保持するため、必ずHULFT10から出力した hulft10_source_snd.txt と hulft10_source_rcv.txt を保管してください。

HULFT10の基本コマンド

utligen -f "C:\temp\hulft10_source_snd.txt" -i snd -id "*" utligen -f "C:\temp\hulft10_source_rcv.txt" -i rcv -id "*" utllist -s -v84 > "C:\temp\hulft10_snd_history.txt" utllist -r -v84 > "C:\temp\hulft10_rcv_history.txt"

上記がHULFT10 for Windowsの4種類の出力コマンドです。履歴の -v84 は固定長（ファイル名付き）で、Excel取込VBAが対応する形式です。HULFT Manager、ExcelはHULFT側で不要です。

同じサーバーにHULFT8とHULFT10が共存している場合、PATHによって別バージョンのコマンドを実行するおそれがあります。BAT先頭の実行コマンド変数に、HULFT10の実行ファイルの絶対パスを設定して確認してください。

操作手順

  1. HULFT10のWindowsサーバーで hulft10_export_all.bat を実行し、BATと同じ場所の hulft10_export フォルダ内へ4ファイルを保存します。すでに同名TXTが存在すると、誤上書き防止のため停止します。
  2. Windows版Excelで Alt + F11 →［挿入］→［標準モジュール］で②のVBAを貼り付けます。Alt + F8 → HULFT10_4Files_Import を実行し、4ファイルを順に選択します。不要なものはファイル選択をキャンセルしてスキップできます。
  3. Excelブックをマクロ有効ブック（.xlsm）として保存。管理情報を編集する場合は、③のVBAを別の標準モジュールへ貼り付けます。
  4. Alt + F8 → HULFT10_ExportCardsForImport を実行。元の配信・集信管理TXTを順に指定した後、別の空フォルダを出力先に選びます。
  5. 生成される hulft10_snd.txt / hulft10_rcv.txt を確認し、④のBATと同じフォルダに配置します。
  6. HULFT10のテスト環境で④のBATを実行。エラーやIDごとの成否をログと管理画面で照合してください。

重要：先に元のTXTを一切編集せずExcelに取り込み、そのまま再出力し、元ファイルとの差分がほぼないかを確認してください。その後1項目だけ編集し、変更箇所だけが変わることを確認してください。HULFT10実機での動作は未検証です。

4種類のTXTを一括出力するBAT

配信管理・集信管理・配信履歴・集信履歴を4つのTXTに保存します。

GitHubで元ファイルを見る（hulft10_export_all.bat）

コードを表示する
@echo off
setlocal EnableExtensions DisableDelayedExpansion
REM HULFT10 for Windows: export 4 types to separate TXT files.
REM ASCII-only BAT: suitable for ANSI or UTF-8 without BOM.
REM The directory of this BAT determines the output folder.
REM If V8 and V10 are both installed, replace command names with full V10 exe paths.
set "UTLIGEN=utligen"
set "UTLLIST=utllist"
set "OUT=%~dp0hulft10_export"
set "LOG=%OUT%\export_result.log"

if not exist "%OUT%" mkdir "%OUT%"
if not exist "%OUT%" (
    echo ERROR: Cannot create "%OUT%".
    pause
    exit /b 1
)

if not exist "%UTLIGEN%" (
    where "%UTLIGEN%" >nul 2>&1
    if errorlevel 1 goto MissingProgram
)
if not exist "%UTLLIST%" (
    where "%UTLLIST%" >nul 2>&1
    if errorlevel 1 goto MissingProgram
)

REM Never overwrite files in an existing export folder.
if exist "%OUT%\hulft10_source_snd.txt" goto Exists
if exist "%OUT%\hulft10_source_rcv.txt" goto Exists
if exist "%OUT%\hulft10_snd_history.txt" goto Exists
if exist "%OUT%\hulft10_rcv_history.txt" goto Exists

echo ==== HULFT10 export ==== > "%LOG%"
echo utligen path: %UTLIGEN% >> "%LOG%"
echo utllist path: %UTLLIST% >> "%LOG%"

echo [1/4] SEND management ...
"%UTLIGEN%" -f "%OUT%\hulft10_source_snd.txt" -i snd -id "*" >> "%LOG%" 2>&1
if errorlevel 1 goto Failure

echo [2/4] RECEIVE management ...
"%UTLIGEN%" -f "%OUT%\hulft10_source_rcv.txt" -i rcv -id "*" >> "%LOG%" 2>&1
if errorlevel 1 goto Failure

echo [3/4] SEND history (V84) ...
"%UTLLIST%" -s -v84 > "%OUT%\hulft10_snd_history.txt" 2>> "%LOG%"
if errorlevel 1 goto Failure

echo [4/4] RECEIVE history (V84) ...
"%UTLLIST%" -r -v84 > "%OUT%\hulft10_rcv_history.txt" 2>> "%LOG%"
if errorlevel 1 goto Failure

echo SUCCESS. Exported files: >> "%LOG%"
dir /b "%OUT%\hulft10_*.txt" >> "%LOG%"
echo.
echo Export complete. Folder: "%OUT%"
echo Review "%LOG%" and data counts.
pause
exit /b 0

:Exists
echo ERROR: One or more output TXT files already exist.
echo Move the previous files or use a NEW export folder.
echo No files were exported this time.
pause
exit /b 2

:MissingProgram
echo ERROR: HULFT CLI command not found in PATH.
echo Run on the HULFT10 server or specify the full HULFT10 exe path.
pause
exit /b 3

:Failure
echo ERROR: Export interrupted. See "%LOG%".
echo Files exported before the error may exist. They are NOT complete backup.
pause
exit /b 1

Excelへ取り込むVBA

4種類のTXTをそれぞれ別シートへ。ファイルIDを文字列のまま保持します。

GitHubで元ファイルを見る（hulft10_excel_import.bas）

コードを表示する
Option Explicit

' HULFT10 for Windows / Excel VBA
' Source: HULFT10 utligen cards (snd/rcv), utllist -s/-r -v84 histories.
' HULFT10 send cards may contain COMPMODE; columns are discovered automatically.
' Paste ALL lines into one standard module (Alt+F11 > Insert > Module).
' Execute: HULFT10_4Files_Import
' Windows Excel only. No references required (late binding).

Private Const DEFAULT_TEXT_CHARSET As String = "shift_jis"
Private Const MASK_SECRET_VALUES As Boolean = True
Private Const HISTORY_BATCH_SIZE As Long = 2000
Private Const EXCEL_MAX_ROW As Long = 1048576

Public Sub HULFT10_4Files_Import()
    Dim oldScreen As Boolean, oldEvents As Boolean
    Dim report As String

    oldScreen = Application.ScreenUpdating
    oldEvents = Application.EnableEvents

    On Error GoTo FatalError
    Application.ScreenUpdating = False
    Application.EnableEvents = False

    report = "HULFT import results" & vbCrLf & String$(24, "-") & vbCrLf
    report = report & ImportWithDialog("配信管理", "SNDFILE", False) & vbCrLf
    report = report & ImportWithDialog("集信管理", "RCVFILE", False) & vbCrLf
    report = report & ImportWithDialog("配信履歴", "", True) & vbCrLf
    report = report & ImportWithDialog("集信履歴", "", True)

    Application.ScreenUpdating = oldScreen
    Application.EnableEvents = oldEvents

    MsgBox report & vbCrLf & vbCrLf & _
           "Save the workbook as .xlsm to keep this macro.", _
           vbInformation, "HULFT text import"
    Exit Sub

FatalError:
    Application.ScreenUpdating = oldScreen
    Application.EnableEvents = oldEvents
    MsgBox "Import stopped: " & Err.Description, vbExclamation
End Sub

Private Function ImportWithDialog(ByVal sheetName As String, _
                                  ByVal cardTag As String, _
                                  ByVal isHistory As Boolean) As String
    Dim picked As Variant
    Dim count As Long, invalidLines As Long
    Dim suffix As String

    On Error GoTo ImportError

    picked = Application.GetOpenFilename( _
        "Text files (*.txt;*.prm;*.dat),*.txt;*.prm;*.dat,All files (*.*),*.*", _
        1, "Choose HULFT file for: " & sheetName, , False)

    If VarType(picked) = vbBoolean Then
        ImportWithDialog = sheetName & ": skipped"
        Exit Function
    End If

    If isHistory Then
        count = ImportHistoryV84(CStr(picked), sheetName, invalidLines)
        If invalidLines > 0 Then
            suffix = " (ignored " & CStr(invalidLines) & " non-V84 lines)"
        End If
    Else
        count = ImportDefinitionCards(CStr(picked), sheetName, cardTag)
    End If

    ImportWithDialog = sheetName & ": " & CStr(count) & " rows" & suffix
    Exit Function

ImportError:
    ImportWithDialog = sheetName & ": ERROR - " & Err.Description
End Function

Private Function ImportDefinitionCards(ByVal filePath As String, _
                                       ByVal sheetName As String, _
                                       ByVal expectedTag As String) As Long
    Dim stm As Object, colIndex As Object, card As Object
    Dim records As Collection
    Dim line As String, key As String, value As String
    Dim eq As Long, rowNum As Long, colNum As Long
    Dim keys As Variant, matrix() As Variant
    Dim ws As Worksheet

    Set records = New Collection
    Set colIndex = CreateObject("Scripting.Dictionary")
    colIndex.CompareMode = vbTextCompare
    colIndex.Add "FILEID", True

    Set stm = OpenHulftText(filePath)

    Do Until stm.EOS
        line = Trim$(stm.ReadText(-2))
        line = StripBom(line)
        If Len(line) = 0 Then GoTo NextCardLine
        If Left$(line, 1) = "#" Or Left$(line, 1) = ";" Then GoTo NextCardLine

        If UCase$(line) = "END" Then
            If Not card Is Nothing Then
                If Len(CStr(card("FILEID"))) > 0 Then records.Add card
                Set card = Nothing
            End If
            GoTo NextCardLine
        End If

        eq = InStr(1, line, "=", vbBinaryCompare)
        If eq <= 1 Then GoTo NextCardLine

        key = UCase$(Trim$(Left$(line, eq - 1)))
        value = Trim$(Mid$(line, eq + 1))

        If key = "SNDFILE" Or key = "RCVFILE" Then
            ' Accept a new card even if a previous card had no END.
            If Not card Is Nothing Then
                If Len(CStr(card("FILEID"))) > 0 Then records.Add card
            End If
            Set card = Nothing

            If key = expectedTag And Len(value) > 0 Then
                Set card = CreateObject("Scripting.Dictionary")
                card.CompareMode = vbTextCompare
                card.Add "FILEID", value
            End If
        ElseIf Not card Is Nothing Then
            If MASK_SECRET_VALUES And IsSecretParameter(key) Then
                value = "[MASKED]"
            End If

            If card.Exists(key) Then
                card(key) = value
            Else
                card.Add key, value
            End If

            If Not colIndex.Exists(key) Then colIndex.Add key, True
        End If

NextCardLine:
    Loop

    If Not card Is Nothing Then
        If Len(CStr(card("FILEID"))) > 0 Then records.Add card
    End If
    stm.Close

    If records.Count = 0 Then
        Err.Raise vbObjectError + 8101, , _
            "No valid " & expectedTag & " cards found. Select utligen output."
    End If
    If records.Count >= EXCEL_MAX_ROW Then
        Err.Raise vbObjectError + 8102, , "Too many rows for one Excel sheet."
    End If

    keys = colIndex.Keys
    ReDim matrix(1 To records.Count + 1, 1 To colIndex.Count)

    For colNum = 0 To UBound(keys)
        matrix(1, colNum + 1) = CStr(keys(colNum))
    Next colNum

    For rowNum = 1 To records.Count
        Set card = records(rowNum)
        For colNum = 0 To UBound(keys)
            key = CStr(keys(colNum))
            If card.Exists(key) Then
                matrix(rowNum + 1, colNum + 1) = _
                    SafeCellString(CStr(card(key)))
            Else
                matrix(rowNum + 1, colNum + 1) = ""
            End If
        Next colNum
    Next rowNum

    Set ws = PrepareOutputSheet(sheetName)
    With ws.Cells(1, 1).Resize(records.Count + 1, colIndex.Count)
        .NumberFormat = "@"
        .Value2 = matrix
    End With
    StyleOutputSheet ws, records.Count + 1, colIndex.Count

    ImportDefinitionCards = records.Count
End Function

Private Function ImportHistoryV84(ByVal filePath As String, _
                                  ByVal sheetName As String, _
                                  ByRef invalidLines As Long) As Long
    Dim stm As Object, ws As Worksheet
    Dim line As String
    Dim batch() As Variant
    Dim found As Long, buffered As Long
    Dim firstRow As Long

    ReDim batch(1 To HISTORY_BATCH_SIZE, 1 To 10)
    Set stm = OpenHulftText(filePath)

    Do Until stm.EOS
        line = StripBom(stm.ReadText(-2))

        If IsValidV84Row(line) Then
            If ws Is Nothing Then
                Set ws = PrepareOutputSheet(sheetName)
                ws.Range("A:J").NumberFormat = "@"
                WriteHistoryHeaders ws
            End If

            If found >= EXCEL_MAX_ROW - 1 Then
                Err.Raise vbObjectError + 8103, , _
                    "History exceeds the Excel row limit."
            End If

            found = found + 1
            buffered = buffered + 1

            ' The positions below are 1-based character offsets.
            ' For HULFT V84, all fields before FILENAME are ASCII.
            batch(buffered, 1) = SafeCellString(Trim$(Mid$(line, 1, 50)))
            batch(buffered, 2) = SafeCellString(Trim$(Mid$(line, 53, 68)))
            batch(buffered, 3) = Trim$(Mid$(line, 123, 10))
            batch(buffered, 4) = Trim$(Mid$(line, 135, 8))
            batch(buffered, 5) = Trim$(Mid$(line, 145, 8))
            batch(buffered, 6) = Trim$(Mid$(line, 155, 18))
            batch(buffered, 7) = Trim$(Mid$(line, 175, 18))
            batch(buffered, 8) = Trim$(Mid$(line, 195, 12))
            batch(buffered, 9) = Trim$(Mid$(line, 209, 3))
            batch(buffered, 10) = SafeCellString(Trim$(Mid$(line, 214)))

            If buffered = HISTORY_BATCH_SIZE Then
                firstRow = 2 + found - buffered
                WriteHistoryBatch ws, batch, buffered, firstRow
                buffered = 0
                Erase batch
                ReDim batch(1 To HISTORY_BATCH_SIZE, 1 To 10)
            End If
        ElseIf Len(Trim$(line)) > 0 Then
            invalidLines = invalidLines + 1
        End If
    Loop

    stm.Close

    If found = 0 Then
        Err.Raise vbObjectError + 8104, , _
            "No HULFT -v84 history rows found. Export with utllist -s/-r -v84."
    End If

    If buffered > 0 Then
        firstRow = 2 + found - buffered
        WriteHistoryBatch ws, batch, buffered, firstRow
    End If

    StyleOutputSheet ws, found + 1, 10
    ImportHistoryV84 = found
End Function

Private Function IsValidV84Row(ByVal line As String) As Boolean
    ' HULFT V84 fixed-width: DATE starts at byte 122 (0-based),
    ' START TIME at 134, END TIME at 144, STATUS at 194.
    ' The prefix uses ASCII, so byte and VBA character offsets agree.
    If Len(line) < 213 Then Exit Function
    If Mid$(line, 137, 1) <> ":" Then Exit Function
    If Mid$(line, 140, 1) <> ":" Then Exit Function
    If Mid$(line, 147, 1) <> ":" Then Exit Function
    If Mid$(line, 150, 1) <> ":" Then Exit Function
    If Mid$(line, 201, 1) <> "-" Then Exit Function
    If Trim$(Mid$(line, 1, 50)) = "" Then Exit Function
    IsValidV84Row = True
End Function

Private Sub WriteHistoryHeaders(ByVal ws As Worksheet)
    Dim hdr(1 To 1, 1 To 10) As Variant
    hdr(1, 1) = "FILEID"
    hdr(1, 2) = "HOST"
    hdr(1, 3) = "開始日"
    hdr(1, 4) = "開始時刻"
    hdr(1, 5) = "終了時刻"
    hdr(1, 6) = "レコード件数"
    hdr(1, 7) = "データサイズ"
    hdr(1, 8) = "ステータス"
    hdr(1, 9) = "接続形態"
    hdr(1, 10) = "ファイル名"
    ws.Range("A1").Resize(1, 10).Value2 = hdr
End Sub

Private Sub WriteHistoryBatch(ByVal ws As Worksheet, _
                              ByRef batch() As Variant, _
                              ByVal usedRows As Long, _
                              ByVal firstRow As Long)
    Dim small() As Variant, r As Long, c As Long

    If usedRows = HISTORY_BATCH_SIZE Then
        ws.Cells(firstRow, 1).Resize(usedRows, 10).Value2 = batch
    Else
        ReDim small(1 To usedRows, 1 To 10)
        For r = 1 To usedRows
            For c = 1 To 10
                small(r, c) = batch(r, c)
            Next c
        Next r
        ws.Cells(firstRow, 1).Resize(usedRows, 10).Value2 = small
    End If
End Sub

Private Function OpenHulftText(ByVal filePath As String) As Object
    Dim raw As Object, result As Object
    Dim bytes As Variant, encoding As String
    Dim lo As Long, size As Long

    encoding = DEFAULT_TEXT_CHARSET

    Set raw = CreateObject("ADODB.Stream")
    raw.Type = 1 ' adTypeBinary
    raw.Open
    raw.LoadFromFile filePath
    size = CLng(raw.Size)

    If size >= 2 Then
        bytes = raw.Read(IIf(size >= 3, 3, 2))
        lo = LBound(bytes)

        If UBound(bytes) - lo >= 2 Then
            If bytes(lo) = 239 And bytes(lo + 1) = 187 _
                             And bytes(lo + 2) = 191 Then
                encoding = "utf-8"
            End If
        End If

        If bytes(lo) = 255 And bytes(lo + 1) = 254 Then
            encoding = "unicode"
        ElseIf bytes(lo) = 254 And bytes(lo + 1) = 255 Then
            encoding = "unicodeFFFE"
        End If
    End If
    raw.Close

    Set result = CreateObject("ADODB.Stream")
    result.Type = 2 ' adTypeText
    result.Charset = encoding
    result.Open
    result.LoadFromFile filePath
    Set OpenHulftText = result
End Function

Private Function PrepareOutputSheet(ByVal sheetName As String) As Worksheet
    Dim ws As Worksheet
    On Error Resume Next
    Set ws = ThisWorkbook.Worksheets(sheetName)
    On Error GoTo 0

    If ws Is Nothing Then
        Set ws = ThisWorkbook.Worksheets.Add( _
                     After:=ThisWorkbook.Worksheets(ThisWorkbook.Worksheets.Count))
        ws.Name = sheetName
    Else
        ' Only these four target sheets are cleared on successful parsing.
        ws.Cells.Clear
    End If

    Set PrepareOutputSheet = ws
End Function

Private Sub StyleOutputSheet(ByVal ws As Worksheet, _
                             ByVal lastRow As Long, _
                             ByVal lastCol As Long)
    Dim c As Long

    With ws.Range(ws.Cells(1, 1), ws.Cells(lastRow, lastCol))
        .AutoFilter
    End With

    With ws.Range(ws.Cells(1, 1), ws.Cells(1, lastCol))
        .Font.Bold = True
        .Font.Color = RGB(255, 255, 255)
        .Interior.Color = RGB(35, 60, 92)
        .RowHeight = 23
    End With

    For c = 1 To lastCol
        ws.Columns(c).AutoFit
        If ws.Columns(c).ColumnWidth > 55 Then
            ws.Columns(c).ColumnWidth = 55
        End If
    Next c
End Sub

Private Function StripBom(ByVal value As String) As String
    If Len(value) > 0 Then
        If AscW(Left$(value, 1)) = -257 Or _
           AscW(Left$(value, 1)) = 65279 Then
            value = Mid$(value, 2)
        End If
    End If
    StripBom = value
End Function

Private Function SafeCellString(ByVal value As String) As String
    value = Replace$(value, Chr$(0), "")
    If Len(value) > 32767 Then value = Left$(value, 32767)
    SafeCellString = value
End Function

Private Function IsSecretParameter(ByVal name As String) As Boolean
    Select Case UCase$(name)
        Case "PASSWORD", "PW", "PASS", "PASSPHRASE", _
             "SECRET", "SECRETKEY", "ENCRYPTKEY", "ENCRYPTION_KEY"
            IsSecretParameter = True
        Case Else
            IsSecretParameter = False
    End Select
End Function

ExcelからTXTへ戻すVBA

元のutligen出力TXTをひな型にして、変更箇所のみを反映します。

コードを表示する
Option Explicit

' HULFT10 for Windows - Excel management list -> edited definition cards.
' Version 10: TEMPLATE-PRESERVING exporter, 2026-11-25
'
' REQUIRED: Keep the original utligen output TXT for each sheet.
' On export, select the ORIGINAL TXT. The program changes only Excel-edited
' fields; other lines, comments, inactive parameters, and ordering stay.
'
' Replace the PREVIOUS export VBA module with this ENTIRE module.
' Keep the separate import VBA module as-is.
' Run: HULFT10_ExportCardsForImport
'
' Scope: only SNDFILE / RCVFILE cards. Histories are never imported into HULFT.
' Safety: no new/deleted/renamed FILEIDs, no overwrite of original/output files.
' Source text defaults to Japanese Windows CP932 (Shift-JIS). UTF-8 BOM and
' UTF-16LE BOM are detected. Output uses the same detected encoding.
' COMPMODE is supported for HULFT10. This tool is untested on real HULFT10.

Private Const SND_ALLOWED As String = _
    "FILENAME INTERVAL BLOCKLEN BLOCKCNT COMP COMPSIZE COMPMODE DEFLATELEVEL " & _
    "TRANSPRTY TRANSTYPE CODESET KJCHNGE SHIFTTRANSACT CLEAR PREJOBID " & _
    "JOBID EJOBID DBID MAILID GRPID FMTID PASSWORD COMMENT"

Private Const RCV_ALLOWED As String = _
    "FILENAME CODESET TRANSMODE ABNORMAL RCVTYPE GENCTL GENMNGNO " & _
    "JOBID EJOBID GRPID PASSWORD MAILID JOBWAIT DATAVERIFY COMMENT"

Private Const SND_REQUIRED As String = _
    "FILENAME COMP TRANSTYPE KJCHNGE GRPID"

Private Const RCV_REQUIRED As String = _
    "FILENAME TRANSMODE ABNORMAL RCVTYPE GENCTL"

Public Sub HULFT10_ExportCardsForImport()
    Dim src(1 To 2) As String
    Dim dst(1 To 2) As String
    Dim encoding(1 To 2) As String
    Dim generated(1 To 2) As String
    Dim cardCount(1 To 2) As Long
    Dim editCount(1 To 2) As Long
    Dim selected(1 To 2) As Boolean
    Dim names(1 To 2) As String
    Dim types(1 To 2) As String
    Dim baseFolder As String, report As String
    Dim ws As Worksheet, rows As Object
    Dim idx As Long, total As Long

    On Error GoTo Fail

    names(1) = "配信管理"
    names(2) = "集信管理"
    types(1) = "SNDFILE"
    types(2) = "RCVFILE"

    For idx = 1 To 2
        Set ws = GetTargetSheet(names(idx))
        If Not ws Is Nothing Then
            selected(idx) = True
            total = total + 1

            Set rows = ReadExcelRecords(ws, types(idx))

            src(idx) = AskOriginalFile(names(idx))
            If Len(src(idx)) = 0 Then Exit Sub

            generated(idx) = PatchUsingOriginal( _
                src(idx), types(idx), rows, encoding(idx), _
                cardCount(idx), editCount(idx))
        End If
    Next idx

    If total = 0 Then
        MsgBox "配信管理・集信管理シートが見つかりません。" & vbCrLf & _
               "先に取込VBAで管理情報を読み込んでください。", vbExclamation
        Exit Sub
    End If

    baseFolder = AskOutputFolder()
    If Len(baseFolder) = 0 Then Exit Sub

    dst(1) = baseFolder & "\hulft10_snd.txt"
    dst(2) = baseFolder & "\hulft10_rcv.txt"

    ' Validate BOTH targets before writing either one.
    For idx = 1 To 2
        If selected(idx) Then
            If StrComp(dst(idx), src(idx), vbTextCompare) = 0 Then
                Err.Raise vbObjectError + 8201, , _
                    "元のTXTと出力先が同じです。別フォルダを選んでください。"
            End If
            If FileExists(dst(idx)) Then
                Err.Raise vbObjectError + 8202, , _
                    "出力先ファイルがすでに存在します: " & dst(idx) & vbCrLf & _
                    "元のTXTや以前の結果の上書き防止のため、" & _
                    "新しい空フォルダを選んでください。"
            End If
        End If
    Next idx

    If MsgBox("Excelの内容を元のutligenテキストへ反映します。" & vbCrLf & _
              "元のTXTは変更せず、別フォルダへ出力します。" & vbCrLf & vbCrLf & _
              "配信管理: " & cardCount(1) & "件 / 変更 " & editCount(1) & "項目" & vbCrLf & _
              "集信管理: " & cardCount(2) & "件 / 変更 " & editCount(2) & "項目" & vbCrLf & vbCrLf & _
              "出力を実行しますか？", vbYesNo + vbQuestion + vbDefaultButton2, _
              "HULFT定義カード出力") <> vbYes Then Exit Sub

    For idx = 1 To 2
        If selected(idx) Then
            SaveTextFile dst(idx), generated(idx), encoding(idx)
        End If
    Next idx

    report = "テキストの出力が完了しました。" & vbCrLf
    For idx = 1 To 2
        If selected(idx) Then
            report = report & vbCrLf & names(idx) & ": " & cardCount(idx) & _
                     "件 / Excel編集 " & editCount(idx) & "項目" & _
                     vbCrLf & dst(idx)
        End If
    Next idx
    MsgBox report & vbCrLf & vbCrLf & _
           "HULFTへの登録前に、元ファイルとの比較と" & _
           "テスト環境での検証を行ってください。", vbInformation
    Exit Sub

Fail:
    MsgBox "安全のため処理を中止しました。" & vbCrLf & _
           Err.Description & vbCrLf & vbCrLf & _
           "※エラーが出力中に発生した場合は出力先も確認してください。", _
           vbExclamation, "HULFT定義カード出力"
End Sub

Private Function ReadExcelRecords(ByVal ws As Worksheet, _
                                  ByVal cardType As String) As Object
    Dim result As Object, row As Object, allowed As Object
    Dim seenHeaders As Object, found As Range
    Dim hdr() As String, v As String, fileID As String
    Dim colCount As Long, rowCount As Long
    Dim r As Long, c As Long, anyData As Boolean

    Set result = NewTextDictionary()
    Set allowed = GetAllowedParameters(cardType)
    Set seenHeaders = NewTextDictionary()

    Set found = ws.Cells.Find(What:="*", LookIn:=xlFormulas, _
                             LookAt:=xlPart, SearchOrder:=xlByRows, _
                             SearchDirection:=xlPrevious, MatchCase:=False)
    If found Is Nothing Then
        Err.Raise vbObjectError + 8210, , ws.Name & "シートが空です。"
    End If
    rowCount = found.Row

    Set found = ws.Cells.Find(What:="*", LookIn:=xlFormulas, _
                             LookAt:=xlPart, SearchOrder:=xlByColumns, _
                             SearchDirection:=xlPrevious, MatchCase:=False)
    colCount = found.Column

    If rowCount < 2 Or colCount < 2 Then
        Err.Raise vbObjectError + 8211, , _
            ws.Name & "シートにヘッダとデータが必要です。"
    End If

    ReDim hdr(1 To colCount)
    For c = 1 To colCount
        v = UCase$(Trim$(CellText(ws.Cells(1, c))))
        If Len(v) = 0 Then
            Err.Raise vbObjectError + 8212, , _
                ws.Name & ": 1行目の見出しが空欄です（" & c & "列）。"
        End If
        If seenHeaders.Exists(v) Then
            Err.Raise vbObjectError + 8213, , _
                ws.Name & ": 項目名が重複しています: " & v
        End If
        If v <> "FILEID" And Not allowed.Exists(v) Then
            Err.Raise vbObjectError + 8214, , _
                ws.Name & ": 不明な列名: " & v & vbCrLf & _
                "HULFTの管理情報項目のみ指定してください。"
        End If
        seenHeaders.Add v, True
        hdr(c) = v
    Next c

    If hdr(1) <> "FILEID" Then
        Err.Raise vbObjectError + 8215, , _
            ws.Name & "シートのA1はFILEIDにしてください。"
    End If

    For r = 2 To rowCount
        Set row = NewTextDictionary()
        anyData = False

        For c = 1 To colCount
            v = CellText(ws.Cells(r, c))
            If HasUnsafeLineBreak(v) Then
                Err.Raise vbObjectError + 8216, , _
                    ws.Name & "!" & ws.Cells(r, c).Address(False, False) & _
                    " に改行・NUL文字があります。"
            End If
            If Len(v) > 0 Then anyData = True
            row.Add hdr(c), v
        Next c

        fileID = CStr(row("FILEID"))
        If Len(fileID) = 0 Then
            If anyData Then
                Err.Raise vbObjectError + 8217, , _
                    ws.Name & "の" & r & "行目はFILEIDが空欄です。"
            End If
        Else
            If Trim$(fileID) <> fileID Or InStr(fileID, "=") > 0 _
               Or UCase$(fileID) = "_INSTANT_TRANSFER_" _
               Or LenB(StrConv(fileID, vbFromUnicode)) > 50 Then
                Err.Raise vbObjectError + 8218, , _
                    ws.Name & "の" & r & "行目のFILEIDが不正です: " & fileID
            End If
            If result.Exists(fileID) Then
                Err.Raise vbObjectError + 8219, , _
                    ws.Name & ": FILEIDが重複しています: " & fileID
            End If
            result.Add fileID, row
        End If
    Next r

    If result.Count = 0 Then
        Err.Raise vbObjectError + 8220, , _
            ws.Name & "に出力可能な管理情報がありません。"
    End If
    Set ReadExcelRecords = result
End Function

Private Function CellText(ByVal cell As Range) As String
    Dim raw As Variant
    If cell.HasFormula Then
        Err.Raise vbObjectError + 8221, , _
            cell.Worksheet.Name & "!" & cell.Address(False, False) & _
            " は数式です。値に変換してから出力してください。"
    End If
    raw = cell.Value2
    If IsError(raw) Then
        Err.Raise vbObjectError + 8222, , _
            cell.Worksheet.Name & "!" & cell.Address(False, False) & _
            " にExcelのエラー値があります。"
    End If
    If IsEmpty(raw) Then
        CellText = ""
    Else
        CellText = CStr(raw)
    End If
End Function

Private Function PatchUsingOriginal( _
    ByVal originalPath As String, ByVal cardType As String, _
    ByVal excelRecords As Object, ByRef encoding As String, _
    ByRef cardCount As Long, ByRef editCount As Long) As String

    Dim originalText As String, eol As String
    Dim sourceLines() As String, outputLines As Collection
    Dim row As Object, touched As Object, finalValues As Object
    Dim visitedIDs As Object, allowed As Object
    Dim currentID As String, name As String, oldValue As String
    Dim newValue As String, line As String, key As Variant
    Dim inactiveName As String, inactiveValue As String
    Dim i As Long, rowNumber As Long, eq As Long
    Dim inside As Boolean, isField As Boolean, startTag As String
    Dim normalized As String, required As String

    originalText = LoadTextFile(originalPath, encoding)
    eol = DetectLineEnding(originalText)
    sourceLines = Split(originalText, eol)
    Set outputLines = New Collection
    Set visitedIDs = NewTextDictionary()
    Set allowed = GetAllowedParameters(cardType)

    If cardType = "SNDFILE" Then
        required = SND_REQUIRED
    Else
        required = RCV_REQUIRED
    End If

    For i = LBound(sourceLines) To UBound(sourceLines)
        line = sourceLines(i)
        normalized = Trim$(line)
        rowNumber = i + 1

        ' Only an active start tag begins a card. # comments are untouched.
        isField = ParseActiveField(line, name, oldValue)
        If isField Then
            If name = "SNDFILE" Or name = "RCVFILE" Then
                If inside Then
                    Err.Raise vbObjectError + 8240, , _
                        "元TXTのENDが不足しています。行=" & rowNumber
                End If
                If name <> cardType Then
                    Err.Raise vbObjectError + 8241, , _
                        "元TXTに異なる管理情報種別があります。行=" & rowNumber & _
                        " / 種別=" & name
                End If
                currentID = Trim$(oldValue)
                If Len(currentID) = 0 Then
                    Err.Raise vbObjectError + 8242, , _
                        "元TXTにFILEID空欄の定義があります。行=" & rowNumber
                End If
                If visitedIDs.Exists(currentID) Then
                    Err.Raise vbObjectError + 8243, , _
                        "元TXT内にFILEIDが重複しています: " & currentID
                End If
                If Not excelRecords.Exists(currentID) Then
                    Err.Raise vbObjectError + 8244, , _
                        "元TXTに存在しExcelに存在しないFILEIDです: " & currentID & vbCrLf & _
                        "削除・ID変更には対応しません。元データとExcelを照合してください。"
                End If

                Set row = excelRecords(currentID)
                Set touched = NewTextDictionary()
                Set finalValues = NewTextDictionary()
                visitedIDs.Add currentID, True
                cardCount = cardCount + 1
                inside = True
            End If
        End If

        If inside And UCase$(normalized) = "END" Then
            ' Do not silently insert a setting not present in the template.
            ' A field may be edited only if active in the original, or
            ' explicitly present as a commented-out KEY=value line.
            For Each key In row.Keys
                name = CStr(key)
                If name <> "FILEID" And Not touched.Exists(name) Then
                    newValue = CStr(row(name))
                    If Len(newValue) > 0 Then
                        Err.Raise vbObjectError + 8245, , _
                            currentID & " / " & name & _
                            ": 元TXTに該当項目がありません。" & vbCrLf & _
                            "元TXTにない新規項目の追加は行いません。" & _
                            "項目とファイルIDを確認してください。"
                    End If
                End If
            Next key

            CheckRequiredFields finalValues, required, currentID
            outputLines.Add line
            inside = False
            currentID = ""
            GoTo NextSourceLine
        End If

        If inside And Not isField Then
            ' An optional parameter already commented in utligen is
            ' activated IN PLACE, rather than appended out of order.
            If ParseCommentedField(line, inactiveName, inactiveValue) Then
                If allowed.Exists(inactiveName) And row.Exists(inactiveName) _
                   And Not touched.Exists(inactiveName) Then
                    newValue = CStr(row(inactiveName))
                    If Len(newValue) > 0 Then
                        If UCase$(Trim$(newValue)) = "[MASKED]" Then
                            Err.Raise vbObjectError + 8253, , _
                                currentID & " / " & inactiveName & _
                                ": コメント行を[MASKED]で有効化できません。"
                        End If
                        line = inactiveName & "=" & newValue
                        touched.Add inactiveName, True
                        finalValues(inactiveName) = newValue
                        editCount = editCount + 1
                    End If
                End If
            End If
        End If

        If inside And isField Then
            If name <> cardType Then
                If Not allowed.Exists(name) Then
                    ' Unknown original parameters are preserved, not discarded.
                    ' They are not made editable by this macro.
                    outputLines.Add line
                    GoTo NextSourceLine
                End If

                If touched.Exists(name) Then
                    Err.Raise vbObjectError + 8246, , _
                        currentID & ": 元TXTで項目が重複しています: " & name
                End If
                touched.Add name, True

                If row.Exists(name) Then
                    newValue = CStr(row(name))
                    If UCase$(Trim$(newValue)) = "[MASKED]" Then
                        If name <> "PASSWORD" Then
                            Err.Raise vbObjectError + 8247, , _
                                currentID & " / " & name & _
                                ": [MASKED] はPASSWORD列以外では使用できません。"
                        End If
                        If UCase$(Trim$(oldValue)) = "%ERROR" Then
                            Err.Raise vbObjectError + 8248, , _
                                currentID & ": 元TXTにPASSWORD=%ERRORがあります。" & _
                                vbCrLf & "実際の暗号キーをExcel側で設定してください。"
                        End If
                        ' Preserve the original password line in place.
                        finalValues(name) = oldValue
                    ElseIf StrComp(Trim$(newValue), Trim$(oldValue), _
                                  vbBinaryCompare) = 0 Then
                        ' Unchanged: keep original spaces and full line.
                        finalValues(name) = oldValue
                    ElseIf Len(newValue) = 0 Then
                        ' Clearing an optional field comments it out.
                        If IsRequired(name, required) Then
                            Err.Raise vbObjectError + 8249, , _
                                currentID & ": 必須項目 " & name & " を空欄にできません。"
                        End If
                        line = "#" & line
                        editCount = editCount + 1
                    Else
                        eq = InStr(1, line, "=", vbBinaryCompare)
                        line = Left$(line, eq) & newValue
                        finalValues(name) = newValue
                        editCount = editCount + 1
                    End If
                Else
                    finalValues(name) = oldValue
                End If
            End If
        End If

        outputLines.Add line

NextSourceLine:
    Next i

    If inside Then
        Err.Raise vbObjectError + 8250, , _
            "元TXTの最終定義にEND行がありません。"
    End If
    If cardCount = 0 Then
        Err.Raise vbObjectError + 8251, , _
            "元TXTに" & cardType & "の定義カードが見つかりません。"
    End If
    If visitedIDs.Count <> excelRecords.Count Then
        For Each key In excelRecords.Keys
            If Not visitedIDs.Exists(CStr(key)) Then
                Err.Raise vbObjectError + 8252, , _
                    "Excelには存在するが元TXTに存在しないFILEIDです: " & CStr(key) & _
                    vbCrLf & "新規IDの追加・FILEID変更には対応しません。"
            End If
        Next key
    End If

    PatchUsingOriginal = JoinLines(outputLines, eol)
End Function

Private Sub CheckRequiredFields( _
    ByVal actual As Object, ByVal required As String, _
    ByVal fileID As String)
    Dim field As Variant, name As String
    For Each field In Split(required, " ")
        name = CStr(field)
        If Not actual.Exists(name) Then
            Err.Raise vbObjectError + 8260, , _
                fileID & ": 必須項目 " & name & " がありません。"
        End If
        If Len(Trim$(CStr(actual(name)))) = 0 Then
            Err.Raise vbObjectError + 8261, , _
                fileID & ": 必須項目 " & name & " が空欄です。"
        End If
    Next field
End Sub

Private Function IsRequired(ByVal name As String, _
                            ByVal required As String) As Boolean
    IsRequired = (InStr(1, " " & required & " ", _
                         " " & name & " ", vbTextCompare) > 0)
End Function

Private Function ParseActiveField(ByVal line As String, _
                                  ByRef name As String, _
                                  ByRef value As String) As Boolean
    Dim s As String, p As Long
    name = ""
    value = ""
    s = Trim$(line)
    If Len(s) = 0 Then Exit Function
    If Left$(s, 1) = "#" Then Exit Function
    p = InStr(1, s, "=", vbBinaryCompare)
    If p < 2 Then Exit Function
    name = UCase$(Trim$(Left$(s, p - 1)))
    value = Mid$(s, p + 1)
    ParseActiveField = True
End Function

Private Function ParseCommentedField(ByVal line As String, _
                                     ByRef name As String, _
                                     ByRef value As String) As Boolean
    Dim s As String, p As Long
    name = ""
    value = ""
    s = Trim$(line)
    If Len(s) = 0 Then Exit Function
    If Left$(s, 1) <> "#" Then Exit Function
    s = Trim$(Mid$(s, 2))
    p = InStr(1, s, "=", vbBinaryCompare)
    If p < 2 Then Exit Function
    name = UCase$(Trim$(Left$(s, p - 1)))
    value = Mid$(s, p + 1)
    ParseCommentedField = True
End Function

Private Function LoadTextFile(ByVal filePath As String, _
                              ByRef charset As String) As String
    Dim raw As Object, txt As Object
    Dim bytes As Variant, pos As Long
    Dim s As String

    charset = "shift_jis"
    Set raw = CreateObject("ADODB.Stream")
    raw.Type = 1
    raw.Open
    raw.LoadFromFile filePath

    If raw.Size = 0 Then
        raw.Close
        Err.Raise vbObjectError + 8270, , "元のTXTが空です: " & filePath
    End If
    If raw.Size >= 2 Then
        bytes = raw.Read(IIf(raw.Size >= 3, 3, 2))
        pos = LBound(bytes)
        If bytes(pos) = 255 And bytes(pos + 1) = 254 Then
            charset = "unicode"
        ElseIf bytes(pos) = 254 And bytes(pos + 1) = 255 Then
            raw.Close
            Err.Raise vbObjectError + 8271, , _
                "UTF-16BEは未対応です。元TXTをShift-JISで取得してください。"
        ElseIf UBound(bytes) >= pos + 2 Then
            If bytes(pos) = 239 And bytes(pos + 1) = 187 _
                                 And bytes(pos + 2) = 191 Then
                charset = "utf-8"
            End If
        End If
    End If
    raw.Close

    Set txt = CreateObject("ADODB.Stream")
    txt.Type = 2
    txt.Charset = charset
    txt.Open
    txt.LoadFromFile filePath
    s = txt.ReadText(-1)
    txt.Close

    If Len(s) > 0 Then
        If AscW(Left$(s, 1)) = -257 Then s = Mid$(s, 2)
    End If
    LoadTextFile = s
End Function

Private Sub SaveTextFile(ByVal filePath As String, _
                         ByVal textData As String, ByVal charset As String)
    Dim stream As Object
    Set stream = CreateObject("ADODB.Stream")
    stream.Type = 2
    stream.Charset = charset
    stream.Open
    stream.WriteText textData
    stream.SaveToFile filePath, 1 ' Create new; fail if it exists.
    stream.Close
End Sub

Private Function DetectLineEnding(ByVal textData As String) As String
    If InStr(1, textData, vbCrLf, vbBinaryCompare) > 0 Then
        DetectLineEnding = vbCrLf
    ElseIf InStr(1, textData, vbLf, vbBinaryCompare) > 0 Then
        DetectLineEnding = vbLf
    ElseIf InStr(1, textData, vbCr, vbBinaryCompare) > 0 Then
        DetectLineEnding = vbCr
    Else
        Err.Raise vbObjectError + 8280, , _
            "元TXTに改行がありません。utligen出力を選択してください。"
    End If
End Function

Private Function JoinLines(ByVal entries As Collection, _
                           ByVal eol As String) As String
    Dim a() As String, i As Long
    ReDim a(0 To entries.Count - 1)
    For i = 1 To entries.Count
        a(i - 1) = CStr(entries(i))
    Next i
    JoinLines = Join(a, eol)
End Function

移行時の注意点

  • HULFT10の違い：配信管理情報の COMPMODE（圧縮モード）をExcelから再出力するVBAの対応項目に追加しています。履歴 -v84 のレイアウトはHULFT10の公式マニュアルで確認しています。
  • 暗号キー：Excel取込では PASSWORD を [MASKED] 表示。再出力VBAは元のTXTにある値を保持します。元TXTや再出力TXTには認証関連の機密情報が含まれる可能性があります。GitHubには絶対に実データを登録しないでください。
  • 高強度暗号強制モード：strongkeymode を変更する移行では、暗号キーが %ERROR となる場合があり、そのままの移行はできません。公式手順に沿って再設定が必要です。
  • 空環境への移行：配信・集信管理情報に加えて、詳細ホスト情報、転送グループ、ジョブ起動、フォーマット等の依存設定を先に登録してください。⑤はこれらを出力する補助BATです。HULFT10 Serverグレードで利用できるスケジュール／ファイルトリガ情報も必要に応じて別途確認してください。
  • 新規登録のみ：④のBATは utliupdt -f を使い、-r は指定しません。既存IDがあればそのIDは登録エラーとなり、処理は次へ進みます。一部成功・一部失敗の可能性があるので、ログと実際の登録内容を照合してください。
  • 文字コード：BAT本文は英数字のみで、ANSI（CP932）かUTF-8（BOMなし）で保存可能です。VBAのTXT読込はShift-JIS（CP932）を標準とし、BOM付きUTF-8/UTF-16LEも扱います。
  • 履歴：配信・集信履歴は保存・比較用です。utliupdt で履歴データをHULFT10へ戻す機能はありません。

  • 配信・集信履歴表示コマンド（utllist / -v84）
  • 管理情報バッチ登録コマンド（utliupdt）
