作成日：2026-09-22

FMTファイル作成コマンド

bcp "dbo.T_受付" format nul -c -f "C:\temp\T_uketuke.fmt" -S "localhost\MIG" -d "shakoumen" -U sa

内容

SQL Server の dbo.T_受付 テーブルを元に、 文字形式（-c）のフォーマットファイルを作成する。

  • 出力先：C:\temp\T_uketuke.fmt
  • SQL Server：localhost\MIG
  • データベース：shakoumen
  • ログインユーザー：sa
注意： コマンド実行後に SQL Server のパスワード入力を求められます。 パスワードはこのHTMLファイルやGitリポジトリには記載しないこと。
