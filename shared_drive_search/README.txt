今回の追加
・共有ドライブの最上位から、さらに1つ上の「共有ドライブ一覧」へ移動できます。
・一覧から別の共有ドライブやその下位フォルダを選べます。
・一覧で「すべての共有ドライブを選択」を押すと、一覧で取得されるドライブを
  1つずつ検索します。アクセス権限のある内容が対象です。
・検索中に一時停止や終了を要求するボタンを追加できます。

「ひとつ上」の場所について
この版は、その場所がGoogleドライブの「共有ドライブ一覧」である場合に対応します。
一覧は複数の共有ドライブを並べる画面であり、通常の親フォルダとしてIDを指定する
必要はありません。コードがDrive APIから共有ドライブ一覧を取得します。
「マイドライブ」「共有アイテム」は別の場所で、この版の対象には含みません。

導入・更新
1. 現在の検索が停止している状態で、スプレッドシートの
   「拡張機能 → Apps Script」を開きます。
2. 現在の DRIVE_ID と、変更している場合は SHEET_NAME を控えます。
3. 共有ドライブ検索用のGASを、この版の Code.gs 全文に置き換えます。
   控えた DRIVE_ID と SHEET_NAME を引き継ぎます。
   DRIVE_ID は初期表示と、先頭が / 1つの相対パス入力の起点になります。
   上位一覧のIDへ変更する必要はありません。
4. 既存の FolderPicker.html も、この版の全文に置き換えます。
   初めて追加する場合は「ファイル」の「＋ → HTML」から名前を
   FolderPicker にして作成します。大文字・小文字を合わせてください。
5. Google Drive API v3（識別子 Drive）は、既存の設定をそのまま使います。
   未追加の場合は「サービス」の「＋」から追加します。
6. 保存して setupDriveSearch を1回実行し、スプレッドシートを再読み込みします。
   v2の配置（B1/B2、見出し3行目、結果4行目）なら入力と既存結果を保持します。
   v1の旧見出しを検出した場合は、旧結果を消してv3の配置に移行します。
7. v2以前の途中経過は引き継がないため、更新後の初回は「新しく検索」を使います。

同じ検索用関数や DRIVE_SEARCH を旧版と新版の両方に残さないでください。
別の用途のコードは保持します。既に独自の onOpen がある場合は、
メニューを追加する処理を1つの onOpen にまとめます。

ボタンへの割り当て
スプレッドシートの「挿入 → 図形描画」で図形を作成し、
図形の「スクリプトを割り当て」に次の関数名を入力します。
末尾の () は付けません。

  フォルダ選択       showFolderPicker
  新しく検索         startDriveSearch
  一時停止           pauseDriveSearch
  終了               stopDriveSearch
  続きから実行       continueDriveSearch

一時停止・終了の関数はv3で追加しています。
旧コードへ関数名だけ割り当てても動きません。先に2ファイルを更新してください。
上部の「共有ドライブ検索」メニューからも同じ操作ができます。

一時停止と終了の違い
  一時停止：現在の処理の区切りで止まり、途中結果と再開位置を保持します。
            D1が一時停止になった後、「続きから実行」で再開できます。
  終了    ：現在の処理の区切りで終了します。表示済み結果は残しますが、
            その検索を途中から再開することはできません。
            再度検索する場合は「新しく検索」を使います。

どちらも停止要求を受けて検索処理自身が止まる方式です。
実行中のDrive API通信を、その瞬間に打ち切る機能ではありません。
D1の「要求」表示はまだ停止完了ではないため、完了表示を待ってください。
終了要求の後で一時停止を押しても、終了要求を優先します。
操作は検索を開始したGoogleアカウントで行います。

即時の強制終了が必要な場合
Apps Scriptの実行一覧（「実行数」またはMy Executions）を開き、
対象の「実行中 / Running」の行の「その他 / ⋮」から
「終了 / Terminate」を選びます。
公式説明：https://developers.google.com/apps-script/guides/dashboard

シートの配置
  B1          名前に含まれる文字列
  B2          検索する場所
  D1          状態、確認件数、該当件数
  A3:F3       見出し
  A4:F以降    検索結果

場所を画面から選ぶ
1. 「フォルダ選択」を押します。B2で指定している場所から開きます。
2. 「ドライブ一覧」で一番上の一覧へ移動できます。
   共有ドライブの直下で「上へ」を押しても一覧へ戻れます。
3. ドライブやフォルダの名前をクリックして、その場所を開きます。
4. 目的の場所で選択ボタンを押すとB2に入り、画面が閉じます。
5. B1へ検索語を入力し、「新しく検索」を押します。

B2の手入力例
  //                       共有ドライブ一覧で取得される全ドライブ
  //営業用ドライブ          名前が「営業用ドライブ」の共有ドライブ全体
  //営業用ドライブ/見積     そのドライブの「見積」と下位の全階層
  /                        設定した DRIVE_ID の共有ドライブ全体
  /営業/見積               設定した DRIVE_ID を起点に「営業 → 見積」
  GoogleドライブのフォルダURL
                           URLが指す共有ドライブ内フォルダと下位階層
  id:フォルダID            IDで正確に指定

画面から選択すると、共有ドライブ名を含む //ドライブ名/... の形で表示します。
手入力パス、URL、IDも、新規検索の開始時に確認済みのパス表示へそろえます。
同名ドライブや同じ親の中の同名フォルダがある場合は、画面またはURL・IDで
指定してください。PCの G:\ などのドライブ文字は使いません。

検索と再開
・選択したフォルダの中と、さらに下の全階層にある名前を部分一致検索します。
・英字大小や全角半角は正規化します。本文検索・誤字補正・空白区切りの
  AND検索は行いません。ゴミ箱とショートカットのリンク先は対象外です。
・名前は取得して比較するため、対象件数に応じて時間がかかります。
・約4分を目安に自動で一時停止します。「続きから実行」で再開します。
・再開待ちの間はB1・B2や結果行を編集・並べ替えないでください。
  条件を変えたときは「新しく検索」を使います。
・処理用シートは自動作成して非表示にします。手動で編集・削除しないでください。
・Drive上のファイルは読み取り対象です。シートの入力表示・結果・進捗は更新します。
・APIのページトークンが失効した場合は「新しく検索」でやり直します。

検証
検索処理と選択画面は、GAS・Sheets・Drive・画面を模したテストで確認しています。
ご利用のGoogleアカウントでの接続は、実際のDRIVE_IDを設定して確認してください。
