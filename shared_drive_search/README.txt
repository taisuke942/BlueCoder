導入・旧版からの更新
1. 検索に使うスプレッドシートを開き、「拡張機能 → Apps Script」を開きます。
   旧版の設定済み DRIVE_ID と、変更している場合は SHEET_NAME を控えます。
2. 旧版の共有ドライブ検索コードを Code.gs の全文に置き換えます。
   同じ検索用関数や DRIVE_SEARCH を旧版と新版の両方に残さないでください。
   別の用途のコードは保持します。既に独自の onOpen がある場合は、
   メニューを追加する処理を1つの onOpen にまとめます。
3. DRIVE_ID に共有ドライブ自体のIDを設定・引き継ぎます。
   SHEET_NAME の初期値は「検索」です。必要なら既存の設定を引き継ぎます。
4. Apps Script左側の「ファイル」の「＋ → HTML」を選び、
   名前を FolderPicker にします。作成されたHTMLの内容を全て消し、
   FolderPicker.html の全文を貼り付けます。大文字・小文字も合わせます。
5. 「サービス」の「＋」から Google Drive API を追加します。
   バージョン v3、識別子 Drive を使います。追加済みなら継続できます。
   標準Google Cloudプロジェクトへ自分で関連付けた場合は、Cloud側でも
   Drive APIを有効にします。
6. 保存して setupDriveSearch を1回実行します。権限確認が表示されたら、
   対象の共有ドライブへアクセスできるアカウントで許可します。
   旧版と一致する見出しを検出すると、旧結果を消して新配置に移行します。
   B1は保持され、B2は /（共有ドライブ全体）になります。
7. スプレッドシートを再読み込みします。
   「共有ドライブ検索」メニューから各機能を使えます。
8. ボタンを使う場合は「挿入 → 図形描画」で図形を作成し、
   図形の「スクリプトを割り当て」に次の関数名を入力します。
   末尾の () は付けません。

   フォルダ選択       showFolderPicker
   新しく検索         startDriveSearch
   続きから検索       continueDriveSearch

   旧版の検索・再開ボタンは、同じ関数名のまま利用できます。

シートの配置
  B1          名前に含まれる文字列
  B2          検索対象のフォルダ（選択画面から自動入力、手入力も可）
  D1          実行状態、確認件数、該当件数
  A3:F3       見出し
  A4:F以降    検索結果

普段の操作
1. B1に検索語を入力します。
2. 「フォルダ選択」ボタン、またはメニューの「フォルダを選択」を開きます。
3. フォルダ名をクリックして開き、目的の場所で「このフォルダを選択」を
   押します。B2にパスが入り、画面が閉じます。
   「上へ」「先頭へ」や上部の階層表示で移動できます。
   共有ドライブの先頭では「共有ドライブ全体を選択」を押せます。
4. 「新しく検索」を実行します。選んだ場所の中と、その下の全階層にある
   ファイル名・フォルダ名を検索します。
5. 大量データでは約4分を目安に一時停止します。
   D1が「完了」になるまで「続きから検索」を実行します。

B2の手入力例
  /                       共有ドライブ全体（空欄も同じ）
  /営業/見積              共有ドライブ先頭から営業 → 見積
  https://drive.google.com/drive/folders/フォルダID
                          指定共有ドライブ内のフォルダURL
  id:フォルダID           IDで正確に指定

バックスラッシュで階層を区切ることもできます。
G:\ などPC上のドライブ文字は使いません。
英数字・ハイフン・アンダースコアのみで10文字以上の裸の値はIDとして
扱います。その形のフォルダ名は先頭に / を付けてください。
同じ親の中に同名フォルダが複数ある場合は、画面またはURL・IDで指定します。
新規検索開始時、URL・ID・手入力パスは確認した現在のパス表示にそろいます。

動作の範囲
・検索語は名前の任意の位置への部分一致です。英字の大小や全角・半角は
  正規化します。本文検索、誤字補正、空白区切りのAND検索は行いません。
・ゴミ箱を除き、実行アカウントで閲覧できる範囲を扱います。
・フォルダへのショートカットのリンク先はたどりません。
・セルの選択だけでは選択画面を開きません。ボタンまたはメニューを使います。
・入力やフォルダ選択だけでは検索を開始しません。「新しく検索」を押します。
・選択画面は現在のフォルダ直下を100件ずつ表示します。
・再開待ちの間はB1・B2や結果行を編集・並べ替えず、開始したアカウントで
  再開してください。条件を変えたときは「新しく検索」を使います。
・処理用の _DriveSearchQueueV2 シートは自動で作成し非表示にします。
  この作業シートは手動で編集・削除しないでください。
・Drive上のファイルは読み取り対象です。シートの入力表示・結果・進捗は
  更新します。実行中のDrive内容の変更は結果に影響する場合があります。
・ページトークンが失効した場合は「新しく検索」でやり直してください。

検証
検索処理と選択画面はNode上のGAS・Sheets・Drive・DOMモックで確認しています。
ご利用のGoogleアカウントでの接続は、実際のDRIVE_IDを設定して確認してください。
