01

どのように検索するか

B1に文字を入力し、メニューの「共有ドライブ検索 → 新しく検索」を実行します。指定した共有ドライブの全階層から、実行したGoogleアカウントで閲覧できる名前を探します。

例えば 見積 で、見積書.xlsx、2026年度_見積一覧.xlsx、株式会社〇〇_見積資料 というフォルダが対象になります。

対象ファイル名・フォルダ名・ショートカット名。ゴミ箱は除外します。
一致の条件検索文字が名前のどこかに含まれる部分一致です。
表記の違い英字の大小、全角・半角を正規化します。例：ＡＢＣ と abc、ﾃｽﾄ と テスト。
空白を含む入力空白も文字として扱います。複数キーワードのAND検索にはなりません。
検索範囲指定した共有ドライブ内の全階層。別ドライブへ向いたショートカットの先はたどりません。

この「あいまい検索」は名前の部分一致です。ファイル本文の検索、誤字の推測、ひらがな・カタカナの同一視は行いません。

PCの「G:」は設定不要ですGASはGoogleドライブ上のデータを読み取ります。コードに設定するのは、Windows上のドライブ文字ではなく、共有ドライブ自体のIDです。

ファイルが大量にある場合

Drive APIの name contains は、公式仕様では前方一致です。名前の途中も判定するため、このコードは最大1,000件ずつ名前などの情報を取得し、GAS側で部分一致を判定します。ファイルの中身はダウンロードしません。

検索のたびに全件の名前を確認するため、件数に応じて時間がかかります。GASの通常の実行上限は1回6分なので、約4分を目安に処理を区切り、続きの位置を保存します。残りはメニューから手動で再開します。

根拠：検索演算子の仕様 ／ files.listとページ取得 ／ GASの実行時間制限

02

初回設定

検索用のシート名は初期設定で 「検索」です。初回設定を実行すると、同じスプレッドシート内に作成されます。

  1. スプレッドシートからApps Scriptを開く

    検索に使うスプレッドシートで、「拡張機能 → Apps Script」を開きます。新しいプロジェクトなら、最初の myFunction を消して、このページのコード全文を貼り付けます。

    既存コードがある場合は消さずに追加してください。既に onOpen() がある場合は、メニュー追加部分をその関数にまとめます。

  2. 共有ドライブIDを設定する

    コード冒頭の次の箇所を、お持ちの共有ドライブIDへ変更します。

    DRIVE_ID: 'ここに共有ドライブIDを入力',

    共有ドライブ自体のIDを指定してください。その中にある下位フォルダのIDや、G:\ のようなパスは指定しません。

    既存シートを使う場合は、SHEET_NAME: '検索' の 検索 を実際のシート名へ変更します。そのシートのA1・C1・2行目に見出しを設定し、A3:Fを出力範囲として使います。

  3. Google Drive APIを追加する

    Apps Scriptの左側にある「サービス」の横の「＋」から Google Drive API を追加します。バージョンは v3、識別子は Drive にします。

    通常の自動作成されたCloudプロジェクトでは、この操作でAPIも有効になります。自分で標準Google Cloudプロジェクトへ関連付けた場合は、Cloud側でもDrive APIを有効にしてください。Google公式の設定手順

  4. 初回設定の関数を実行する

    保存後、上部の関数選択で setupDriveSearch を選び、「実行」をクリックします。権限の確認が表示されたら、共有ドライブへアクセスするGoogleアカウントで許可します。

  5. スプレッドシートを再読み込みする

    上部に「共有ドライブ検索」メニューが表示されれば準備完了です。setupDriveSearch は初回設定用で、毎回の検索には使いません。

04

GASコード全文

「コードをコピー」で全文をコピーし、Apps Scriptへ貼り付けます。変更が必須なのは DRIVE_ID の1か所です。

shared_drive_search.gs
/**
 * 共有ドライブ内の名前を部分一致検索するGAS（2026-11-10）
 *
 * 初回設定:
 * 1. 検索に使うスプレッドシートの「拡張機能 → Apps Script」に貼り付ける。
 * 2. 下の DRIVE_ID を、共有ドライブ自体のIDに変更する。
 * 3. 左側の「サービス +」で Google Drive API（v3 / 識別子 Drive）を追加する。
 * 4. setupDriveSearch を一度実行し、アクセスを許可する。
 *
 * 通常操作:
 * 「検索」シートのB1に文字を入力 → メニュー「共有ドライブ検索 → 新しく検索」。
 * D1が「一時停止」なら、同じメニューの「続きから検索」を実行する。
 * B1入力だけでは自動実行しない。約4分ごとに区切り、必要な回数だけ再開する。
 * 検索中・再開待ちの間は、検索語や結果の行を編集・並べ替えない。
 *
 * 対象: このアカウントから閲覧できる、指定共有ドライブ内の全階層の名前。
 * ゴミ箱は除外。本文検索・誤字補正・別ドライブへのショートカット追跡は行わない。
 * 全角半角と英字大小を正規化した部分一致。空白区切りはAND検索にせず文字として扱う。
 * 毎回、全件の名前などの情報を読み取るため、件数に比例して時間がかかる。
 * ページトークンが失効した場合は「新しく検索」でやり直す。
 *
 * 結果はA3:F以降を使用。新規検索ではこの範囲の前回結果を消去する。
 * Drive上のファイル操作は読み取りのみ。
 * 更新日時の表示はスプレッドシートのタイムゾーンに従う。
 *
 * 仕様確認:
 * https://developers.google.com/workspace/drive/api/guides/ref-search-terms
 * https://developers.google.com/workspace/drive/api/reference/rest/v3/files/list
 * https://developers.google.com/apps-script/guides/services/quotas
 */

const DRIVE_SEARCH = {
  DRIVE_ID: 'ここに共有ドライブIDを入力',
  SHEET_NAME: '検索',
  PAGE_SIZE: 1000,
  RUN_LIMIT_MS: 4 * 60 * 1000,
  STATE_KEY: 'SHARED_DRIVE_NAME_SEARCH_V1'
};

function onOpen() {
  SpreadsheetApp.getUi().createMenu('共有ドライブ検索')
    .addItem('新しく検索', 'startDriveSearch')
    .addItem('続きから検索', 'continueDriveSearch')
    .addToUi();
}

// 初回だけ実行。B1の既存入力は保持する。
function setupDriveSearch() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  let sheet = ss.getSheetByName(DRIVE_SEARCH.SHEET_NAME);
  if (!sheet) {
    sheet = ss.insertSheet(DRIVE_SEARCH.SHEET_NAME);
    // 新規作成した検索専用シートは6列にして、セル数の増加を抑える。
    if (sheet.getMaxColumns() > 6) {
      sheet.deleteColumns(7, sheet.getMaxColumns() - 6);
    }
  }
  if (sheet.getMaxColumns() < 6) {
    sheet.insertColumnsAfter(sheet.getMaxColumns(), 6 - sheet.getMaxColumns());
  }
  if (sheet.getMaxRows() < 3) {
    sheet.insertRowsAfter(sheet.getMaxRows(), 3 - sheet.getMaxRows());
  }
  sheet.getRange('A1').setValue('検索語');
  sheet.getRange('B1').setBackground('#fff2cc');
  sheet.getRange('C1').setValue('状態');
  sheet.getRange(2, 1, 1, 6)
    .setValues([['No.', '種類', '名前', '更新日時', '開くURL', '親フォルダURL']])
    .setFontWeight('bold').setBackground('#d9eaf7');
  sheet.setFrozenRows(2);
  sheet.setColumnWidth(1, 60);
  sheet.setColumnWidth(2, 180);
  sheet.setColumnWidth(3, 350);
  sheet.setColumnWidth(4, 180);
  sheet.setColumnWidths(5, 2, 300);
  ss.setActiveSheet(sheet);
  onOpen();
}

function startDriveSearch() {
  runDriveSearch_(true);
}

function continueDriveSearch() {
  runDriveSearch_(false);
}

function runDriveSearch_(restart) {
  const started = Date.now();
  const lock = LockService.getDocumentLock();
  if (!lock || !lock.tryLock(1000)) {
    throw new Error('別の検索が実行中です。終了後に実行してください。');
  }
  let sheet;
  let processing = false;
  try {
    if (typeof Drive === 'undefined') {
      throw new Error('Apps Scriptの「サービス +」でGoogle Drive API（v3）を追加してください。');
    }
    const driveId = DRIVE_SEARCH.DRIVE_ID.trim();
    if (!/^[A-Za-z0-9_-]+$/.test(driveId)) {
      throw new Error('DRIVE_IDに共有ドライブ自体のIDを設定してください。');
    }
    const ss = SpreadsheetApp.getActiveSpreadsheet();
    sheet = ss.getSheetByName(DRIVE_SEARCH.SHEET_NAME);
    if (!sheet) throw new Error('先にsetupDriveSearchを実行してください。');

    const keyword = sheet.getRange('B1').getDisplayValue().trim();
    if (!keyword) throw new Error('B1に検索する文字を入力してください。');
    const key = normalizeDriveName_(keyword);
    const owner = Session.getTemporaryActiveUserKey();
    const props = PropertiesService.getDocumentProperties();
    let state;

    if (restart) {
      state = {
        driveId: driveId, sheetId: sheet.getSheetId(), owner: owner,
        keyword: keyword, key: key, token: '',
        nextRow: 3, checked: 0, hits: 0, done: false
      };
      props.setProperty(DRIVE_SEARCH.STATE_KEY, JSON.stringify(state));
    } else {
      const saved = props.getProperty(DRIVE_SEARCH.STATE_KEY);
      if (!saved) throw new Error('再開する検索がありません。「新しく検索」を実行してください。');
      state = JSON.parse(saved);
      if (state.owner !== owner) {
        throw new Error('検索を開始したGoogleアカウントで再開してください。');
      }
      if (state.driveId !== driveId || state.sheetId !== sheet.getSheetId() || state.key !== key) {
        throw new Error('検索条件が変わっています。「新しく検索」を実行してください。');
      }
      if (state.done) {
        showDriveStatus_(sheet, state, '完了');
        return;
      }
    }

    processing = true;
    // 前回、書き込み後・進捗保存前に止まった場合も二重追記を防ぐ。
    clearDriveResultsFrom_(sheet, state.nextRow);
    showDriveStatus_(sheet, state, '検索中');
    SpreadsheetApp.flush();

    while (Date.now() - started < DRIVE_SEARCH.RUN_LIMIT_MS) {
      const options = {
        corpora: 'drive', driveId: state.driveId,
        includeItemsFromAllDrives: true, supportsAllDrives: true,
        spaces: 'drive', q: 'trashed = false', pageSize: DRIVE_SEARCH.PAGE_SIZE,
        fields: 'nextPageToken,incompleteSearch,files(id,name,mimeType,modifiedTime,webViewLink,parents)'
      };
      if (state.token) options.pageToken = state.token;
      const page = Drive.Files.list(options);
      if (page.incompleteSearch) {
        throw new Error('Drive APIが検索未完了を返しました。「新しく検索」でやり直してください。');
      }

      const files = page.files || [];
      const rows = files
        .filter(file => normalizeDriveName_(file.name).includes(state.key))
        .map((file, i) => {
          const folder = file.mimeType === 'application/vnd.google-apps.folder';
          const shortcut = file.mimeType === 'application/vnd.google-apps.shortcut';
          const name = String(file.name || '');
          return [
            state.hits + i + 1,
            folder ? 'フォルダ' : (shortcut ? 'ショートカット' : 'ファイル'),
            /^[=']/.test(name) ? "'" + name : name,
            file.modifiedTime ? new Date(file.modifiedTime) : '',
            file.webViewLink || (folder
              ? 'https://drive.google.com/drive/folders/' + file.id
              : 'https://drive.google.com/file/d/' + file.id + '/view'),
            file.parents && file.parents.length
              ? 'https://drive.google.com/drive/folders/' + file.parents[0] : ''
          ];
        });

      if (rows.length) {
        const endRow = state.nextRow + rows.length - 1;
        if (endRow > sheet.getMaxRows()) {
          sheet.insertRowsAfter(sheet.getMaxRows(), endRow - sheet.getMaxRows());
        }
        sheet.getRange(state.nextRow, 3, rows.length, 1).setNumberFormat('@');
        sheet.getRange(state.nextRow, 1, rows.length, 6).setValues(rows);
        sheet.getRange(state.nextRow, 4, rows.length, 1)
          .setNumberFormat('yyyy/mm/dd hh:mm:ss');
      }

      state.checked += files.length;
      state.hits += rows.length;
      state.nextRow += rows.length;
      state.token = page.nextPageToken || '';
      state.done = !state.token;
      showDriveStatus_(sheet, state, '検索中');
      // シートへの書き込みを確定してから、次のページ位置を保存する。
      SpreadsheetApp.flush();
      props.setProperty(DRIVE_SEARCH.STATE_KEY, JSON.stringify(state));
      if (state.done) break;
    }

    showDriveStatus_(sheet, state, state.done
      ? '完了' : '一時停止：「続きから検索」を実行');
    SpreadsheetApp.flush();
    ss.toast(state.done ? '検索が完了しました。' : '続きから検索できます。', '共有ドライブ検索', 8);
  } catch (error) {
    if (sheet && processing) {
      sheet.getRange('D1').setValue('中断（未完了）：' + error.message);
    }
    throw error;
  } finally {
    lock.releaseLock();
  }
}

function normalizeDriveName_(value) {
  return String(value || '').normalize('NFKC').toLowerCase();
}

function clearDriveResultsFrom_(sheet, row) {
  const lastRow = sheet.getLastRow();
  if (lastRow >= row) {
    sheet.getRange(row, 1, lastRow - row + 1, 6).clearContent();
  }
}

function showDriveStatus_(sheet, state, label) {
  sheet.getRange('D1').setValue(
    label + ' ｜ 確認 ' + state.checked.toLocaleString('ja-JP') + '件' +
    ' ／ 該当 ' + state.hits.toLocaleString('ja-JP') + '件' +
    ' ｜ 検索語：' + state.keyword
  );
}

05

困ったとき

「Drive is not defined」など、Driveのエラーが出る

「サービス ＋」からGoogle Drive APIを追加し、v3・識別子Driveになっているか確認してください。共有ドライブIDを設定していることと、実行アカウントに対象ドライブの閲覧権限があることも確認します。

「共有ドライブ検索」メニューが出ない

setupDriveSearchを一度実行し、スプレッドシートを再読み込みしてください。既存プロジェクトに追加した場合は、onOpen()が重複していないか確認します。

一時停止した後、再開するとエラーになる

B1、共有ドライブID、シート、Googleアカウントが検索開始時と同じか確認してください。ページトークンは公式仕様で通常数時間有効です。長時間置いた後にpageToken関連のエラーが出た場合は、「新しく検索」で最初から実行してください。APIの一時的なエラーなら、同じ条件のまま「続きから検索」で再試行できます。

ファイルが見つからない・0件になる

検索対象は名前です。本文中だけに含まれる文字はヒットしません。複数語を空白で区切ると、その空白を含めた文字列で検索します。また、Googleアカウントから閲覧できない項目、ゴミ箱内、別ドライブへのショートカットの先は対象外です。

大量のファイルを毎回もっと速く検索したい

このコードは毎回すべての名前を確認する方式です。件数が多く、繰り返しすばやく検索する必要がある場合は、ファイル名の一覧を事前に作成し、その一覧を検索・更新する索引方式が適しています。このコードには索引作成機能は含めていません。

検索時の結果は、完全な同一時点の一覧か

検索中にファイルの追加・削除・名前変更があると、結果に影響することがあります。Drive APIのページ取得は、共有ドライブ全体を固定した同一時点のスナップショットではありません。
